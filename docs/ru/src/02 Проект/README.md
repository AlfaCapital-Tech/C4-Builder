# Проект

Проект c4builder — это папка с файлом `.c4builder`. В ней две главные папки: **исходники**
(`src`, ключ `rootFolder`) и **выход** (`docs`, ключ `distFolder`). Все команды запускаются из
папки проекта: пути в конфиге считаются от неё.

## Папка = страница

Каждая папка внутри исходников — одна страница документации. По C4-модели это обычно
система, контейнер или компонент, но подойдёт любая тема: ADR, глоссарий, runbook.

```text
demo/
├── .c4builder              конфиг проекта
├── docs/                   выход: пересоздаётся при каждой сборке
└── src/                    исходники
    ├── context.md          корень = главная страница
    ├── context.puml
    ├── styles.iuml         общая тема диаграмм (подключается через !include)
    └── 1 Internet Banking System/
        ├── system.md
        ├── system.puml
        └── API Application/
            ├── container.md
            └── container.puml
```

Сборка обходит дерево и склеивает все `.md` и диаграммы папки в одну страницу:

- **Заголовок страницы** — имя папки. Если первый `.md` начинается со своего `# Заголовка`,
  берётся он.
- **Порядок страниц** — порядок файловой системы. Чтобы задать его явно, используйте
  числовые префиксы: `1 Контекст`, `2 Контейнеры`. Префикс виден в заголовке в sidebar.
- **Диаграммы** вставляются картинками. По умолчанию — перед текстом страницы, после текста —
  с `diagramsOnTop: false`.
- **Диаграмму можно поставить в любое место текста** ссылкой на её исходник:
  `![контейнеры](container.puml)`. Такая диаграмма в общий блок уже не попадает.
- **Файлы и папки с префиксом `_`** не становятся страницами и не рендерятся отдельно, но
  доступны для `!include` и D2-импортов. Это место для общих библиотек: `_c4lib.d2`, `_common.iuml`.
- **Прочие файлы** (картинки, вложения) копируются в выход рядом со страницей, если не
  включён `excludeOtherFiles`. Картинку кладите рядом с `.md`, который на неё ссылается.

## Служебные файлы

| Файл | Зачем | В git |
|---|---|---|
| `.c4builder` | конфиг проекта | да |
| `.c4builder.cache` | чексуммы диаграмм: неизменённые не рендерятся заново | нет |
| `.c4builder.lock` | лок сборки: две сборки в одной папке не пишут выход одновременно | нет |
| `docs_bk/` | копия прошлого выхода на время сборки; при ошибке остаётся как резерв | нет |

Папку выхода c4builder удаляет и создаёт заново на каждой сборке, поэтому своё туда не
кладите. Коммитить ли сам выход, зависит от вывода: markdown по папкам удобно держать в
репозитории, сайт обычно собирается в CI.
