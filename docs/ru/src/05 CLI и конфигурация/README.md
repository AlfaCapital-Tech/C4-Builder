# CLI и конфигурация

## Команды

| Команда | Что делает |
|---|---|
| `c4builder` | собирает проект в текущей папке; без конфига сначала запускает мастер |
| `c4builder new` | создаёт проект из шаблона в новой папке (то же, что `--new`) |
| `c4builder new --name demo -y` | то же без вопросов: полный конфиг со значениями по умолчанию |
| `c4builder config` | мастер настройки с текущими значениями (то же, что `--config`) |
| `c4builder site` | собирает и раздаёт сайт локально (то же, что `--site`) |
| `c4builder --site -w` | то же с пересборкой на каждое сохранение и перезагрузкой браузера |
| `c4builder check <файлы...>` | проверяет диаграммы `.puml`, `.iuml`, `.d2` без сборки, код выхода 0 или 1 |
| `c4builder jre info` | какая Java будет использована (JSON) |
| `c4builder jre install [--force]` | скачать JRE в кэш заранее; `--force` — даже если есть системная Java |
| `c4builder --list` | показать текущий конфиг |
| `c4builder --reset` | очистить конфиг проекта |
| `c4builder --docs` | краткая справка по ключам конфига и адрес этой документации |

Флаги:

| Флаг | Значение |
|---|---|
| `-c, --config-file <путь>` | другой файл конфига вместо `.c4builder` |
| `-w, --watch` | пересобирать при изменениях в исходниках и папках плагинов |
| `-o, --open` | открыть сайт в браузере (с `--site`) |
| `-p, --port <n>` | порт для `--site` (по умолчанию `webPort` из конфига, 3000) |
| `--system-fonts` | рендер системными шрифтами на один запуск |
| `-V, --version` | версия |

## Как читается конфиг

`.c4builder` — JSON в папке проекта. Первая сборка задаёт недостающие ключи через мастер и
ставит `hasRun: true`; после этого `c4builder` собирает без вопросов. `new -y` сразу пишет
полный конфиг, поэтому мастера не будет вовсе.

Ключи проверяются схемой. Значение не того типа останавливает сборку с ошибкой, где назван
ключ, а `c4builder config` позволяет его исправить. Неизвестные ключи молча
отбрасываются — так старый c4builder не падает на конфиге от нового. Ключи функций, удалённых
из старых версий, дают предупреждение с их списком, сборка продолжается.

## Ключи `.c4builder`

| Ключ | По умолчанию | Что задаёт |
|---|---|---|
| `projectName` | имя при создании | имя проекта: заголовок сайта и единого файла |
| `homepageName` | `Overview` | заголовок корневой страницы |
| `rootFolder` | `src` | папка исходников |
| `distFolder` | `docs` | папка выхода, пересоздаётся при каждой сборке |
| `generateWEB` | `true` | сайт на docsify |
| `generateMD` | `true` | markdown по папкам |
| `generateCompleteMD` | `false` | один файл `<projectName>.md` |
| `includeTableOfContents` | `true` | дерево страниц вверху каждого markdown-файла |
| `includeNavigation` | `false` | ссылки на родителя и дочерние страницы в markdown |
| `includeBreadcrumbs` | `true` | путь страницы под заголовком |
| `diagramsOnTop` | `true` | диаграммы до текста страницы |
| `includeLinkToDiagram` | `false` | ссылка вместо картинки диаграммы |
| `embedDiagram` | `false` | картинка в markdown base64-строкой |
| `excludeOtherFiles` | `false` | не копировать прочие файлы из исходников |
| `generateLocalImages` | `true` | локальный рендер; `false` — ссылки на онлайн-сервер |
| `plantumlServerUrl` | `https://www.plantuml.com/plantuml` | сервер для `generateLocalImages: false` |
| `diagramFormat` | `svg` | `svg` или `png` |
| `d2Layout` | `dagre` | раскладка D2: `dagre` или `elk` |
| `useSystemFonts` | `false` | системные шрифты вместо вендорного |
| `charset` | `UTF-8` | кодировка исходников PlantUML |
| `webTheme` | `vendor/vue.css` | CSS-тема docsify |
| `supportSearch` | `true` | поиск в sidebar |
| `repoUrl` | пусто | ссылка на репозиторий в углу сайта |
| `executeScript` | `false` | выполнение `<script>` в страницах и подключение swagger-ui |
| `docsifyTemplate` | пусто | путь к модулю со своим шаблоном `index.html` |
| `webPort` | `3000` | порт `c4builder site` |
| `webFileName` | — | одно имя `.md` для всех страниц сайта вместо имени папки |
| `excludeSidebarFolderByPath` | — | список путей (от папки проекта, например `src/Архив`), скрытых из sidebar |
| `plugins` | `[]` | плагины сборки, см. [Плагины](06%20Плагины/06%20Плагины.md) |

Конфиг сайта этой документации — живой пример: `docs/ru/.c4builder` в репозитории.

## Свой шаблон docsify

`docsifyTemplate` указывает на ESM- или CommonJS-модуль, который экспортирует функцию.
Она получает объект настроек docsify (имя, sidebar, тема, поиск) и возвращает HTML для
`index.html`. Отправная точка — встроенный шаблон в `src/core/compose/docsify.template.ts`.
