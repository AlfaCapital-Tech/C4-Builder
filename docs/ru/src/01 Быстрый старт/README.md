# Быстрый старт

## Установка

```bash
npm i -g @alfacapital-tech/c4builder
```

Нужен Node.js 20.19 или новее. `npm install` без тега ставит последний стабильный релиз.

Для рендера PlantUML нужна Java 17+. Если `java` есть в `JAVA_HOME` или в `PATH`, c4builder
возьмёт её; если нет — при первой сборке скачает приватную JRE (Temurin) в свой кэш.
Graphviz не нужен: раскладку считает встроенный в PlantUML движок Smetana. PlantUML-jar и шрифт
диаграмм входят в пакет.

```bash
c4builder jre info      # какая Java будет использована (JSON: версия, путь кэша)
c4builder jre install   # скачать JRE заранее: перед работой офлайн или в образ CI
```

Если ставить Node и Java не хочется, есть [Docker-образ](07%20Docker%20и%20CI/07%20Docker%20и%20CI.md),
в нём уже всё есть.

## Первый проект

```bash
c4builder new --name demo -y   # проект из шаблона с готовым конфигом, без вопросов
cd demo
c4builder                      # сборка в docs/
c4builder site                 # сайт на http://localhost:3000
```

Без `-y` команда `new` спросит имя проекта, а первая сборка проведёт через мастер настройки.
Флаг `--new` — то же самое, что `new`.

В новом проекте лежит демо «Internet Banking System» из C4-модели: контекст, контейнеры,
deployment, динамическая диаграмма, sequence, class и ditaa, страница с кириллицей и пример
на D2. Все C4-диаграммы подключают библиотеку через stdlib (`!include <C4/C4_Container>`):
C4-PlantUML встроен в jar, поэтому сборке не нужен интернет.

## Живой предпросмотр

```bash
c4builder --site -w
```

Собирает проект, поднимает локальный сервер и пересобирает сайт на каждое сохранение в `src/`.
Браузер перезагружается сам и сохраняет позицию прокрутки. `-o` открывает браузер,
`-p 8080` меняет порт.

## Изменить настройки

`c4builder config` (или `--config`) снова запускает мастер, подставляя текущие значения;
`c4builder --list` показывает конфиг. `.c4builder` — обычный JSON, его можно править руками:
все ключи описаны на странице [CLI и конфигурация](05%20CLI%20и%20конфигурация/05%20CLI%20и%20конфигурация.md).

## Релиз-кандидаты

Пре-релизы `X.Y.Z-rc.N` публикуются под npm-тегом `rc` и не трогают `latest`:

```bash
npm i -g @alfacapital-tech/c4builder@rc
```

Чтобы вернуться на стабильную версию, поставьте пакет с тегом `latest`.
