# C4-Builder

**Архитектура как код, которую агент пишет, проверяет и читает.**

C4-Builder — CLI, который собирает папку с markdown и диаграммами PlantUML или D2 в
документацию: сайт на docsify, markdown по папкам или один файл. Папки задают иерархию
[C4-модели](https://c4model.com/) (система → контейнер → компонент), а git хранит историю
архитектурных решений вместе с кодом: правка архитектуры проходит ревью в pull request,
как любое другое изменение.

Этот сайт собран самим c4builder из папки `docs/` репозитория, диаграммы на нём
отрендерены при сборке в CI.

## Чем форк отличается от upstream

Оригинальный C4-Builder не развивается: последний коммит — март 2024 года, последний
npm-релиз `c4builder` 0.2.16 вышел в 2022-м. В Альфа-Капитале на нём собирается
архитектурный репозиторий на сотню с лишним диаграмм, поэтому мы продолжаем проект как
поддерживаемый форк и развиваем его под работу с AI-агентами:

- **Детерминированный офлайн-рендер.** PlantUML-jar, шрифт и движки поставляются с пакетом,
  раскладку считает встроенный в PlantUML движок Smetana, Graphviz не нужен. Одни и те же
  исходники дают одинаковые SVG на ноутбуке, в CI и в Docker, а сеть при сборке не нужна.
- **`c4builder check` — обратная связь за секунды.** Проверяет отдельные диаграммы тем же
  движком, что и сборка, и возвращает код выхода и номер строки с ошибкой. Агент правит
  `.puml` и сразу узнаёт, сломал ли он что-нибудь, без человека и без полной сборки.
- **Плагины.** `openspec` публикует спеки и change'и рядом с C4-моделью, `openapi` —
  контракты сервисов офлайн-страницами swagger-ui.
- **D2** вторым движком диаграмм, PNG через resvg, Java по желанию: если её нет, c4builder
  скачает JRE сам.
- **Инженерная база.** TypeScript, golden-снапшоты рендера, CI на каждый pull request,
  npm-пакет и Docker-образ по тегу релиза.

Полный список изменений — в
[CHANGELOG](https://github.com/AlfaCapital-Tech/C4-Builder/blob/master/CHANGELOG.md).

## Цикл с агентом

1. Агент (или вы) правит `.md` и `.puml` в `src/`.
2. `c4builder check <файлы>` отвечает, собирается ли диаграмма, и показывает строку ошибки.
3. `c4builder --site -w` пересобирает сайт на каждое сохранение и обновляет браузер.

Скиллы для агентов, `AGENTS.md` в новом проекте и `llms.txt` с исходниками диаграмм — на
странице [Агенты](08%20Агенты/08%20Агенты.md).
