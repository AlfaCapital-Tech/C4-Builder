# wireflow-diagrams Specification

## Purpose
Рендер пользовательских сценариев из экспорта редактора Wireflow (`*.wireflow.json`) в
картинки сайта при сборке — локально, без браузера и сети, детерминированно.

## Requirements

### Requirement: Источник wireflow — файлы экспорта редактора

Сборка SHALL считать wireflow-диаграммой файл дерева исходников с именем `wireflow.json` или
оканчивающимся на `.wireflow.json` (без учёта регистра). Прочие `.json`-файлы MUST
обрабатываться как раньше. Выходной файл MUST называться по имени источника без
`.wireflow.json` (`wireflow.json` → `wireflow.svg`).

#### Scenario: Файл сценария рядом со страницей
- **WHEN** в папке страницы лежит `checkout.wireflow.json`
- **THEN** на странице — картинка `checkout.svg` (или `checkout.png` при `diagramFormat: png`)

#### Scenario: Обычный JSON не затронут
- **WHEN** в папке страницы лежит `data.json`
- **THEN** он копируется в выход как прочий файл и не рендерится

#### Scenario: Коллизия имён выхода
- **WHEN** в одной папке лежат `checkout.puml` и `checkout.wireflow.json`
- **THEN** сборка прерывается ошибкой о совпадающем имени выхода, как для других движков

### Requirement: Поддерживаемые версии формата

Движок SHALL принимать файлы `{"format": "wireflow", "version": N, "diagram": {...}}` с версией
от 2 до 4. Файл старого формата (версия 1, файлы без поля `format`), версии новее 4 или не
JSON MUST давать ошибку с именем файла и причиной; для старых форматов причина MUST
предлагать пересохранить файл в текущем редакторе Wireflow.

#### Scenario: Текущий формат
- **WHEN** файл экспортирован текущим редактором (`version: 4`)
- **THEN** диаграмма рендерится

#### Scenario: Старый формат gg-editor
- **WHEN** файл имеет `version: 1` или не имеет поля `format`
- **THEN** ошибка называет файл и предлагает открыть и пересохранить его в текущем Wireflow

#### Scenario: Файл новее движка
- **WHEN** файл имеет `version: 5`
- **THEN** ошибка называет файл и неподдерживаемую версию

### Requirement: Состав рендера

Рендер SHALL отображать все узлы и рёбра файла в геометрии редактора:
- карточки экранов — рамка, заголовок (если включён) и картинка шаблона экрана или встроенное изображение карточки;
- заметки с многострочным текстом;
- группы рамкой с подписью вокруг вложенных узлов;
- рёбра нужного вида (кривая, ступенька, скруглённая ступенька) со стрелкой, цветом, толщиной и подписью.

Настройки оценки (`settings`, ставки, этапы) MUST NOT влиять на картинку.

Символы, недопустимые в XML 1.0 (управляющие C0, кроме табуляции и переводов строки, U+FFFE,
U+FFFF, одиночные суррогаты), в текстах, подписях, цветах и id MUST NOT делать SVG невалидным:
U+000B и U+000C в текстах SHALL трактоваться как перевод строки, остальные — отбрасываться;
раскладка текста MUST считаться по той же очищенной строке, что попадает в SVG.

#### Scenario: Сценарий с группой и заметкой
- **WHEN** файл содержит группу с двумя карточками, заметку и ребро `smoothstep` с подписью
- **THEN** SVG содержит рамку группы с подписью, обе карточки с шаблонами экранов, заметку с текстом и ребро со стрелкой и подписью

#### Scenario: Кириллица
- **WHEN** подписи карточек, заметок и рёбер — на русском
- **THEN** текст в SVG и PNG отображается вендорным шрифтом без пропущенных символов

#### Scenario: Управляющие символы в текстах
- **WHEN** текст заметки содержит U+000B (разрыв строки из Word), а цвет ребра — U+0001
- **THEN** заметка переносит строку на месте U+000B, цвет ребра применяется без U+0001, SVG валиден, PNG растеризуется, `check` выводит `✓`

#### Scenario: Встроенное изображение карточки
- **WHEN** карточка использует собственную картинку (`own-image`, PNG или JPEG)
- **THEN** изображение отрисовано в карточке без обращения к сети

### Requirement: Рендер wireflow без браузера и сети

Рендер MUST выполняться в процессе сборки без браузера, без сетевых запросов и без
дополнительных npm-пакетов. Шаблоны экранов MUST браться из каталога, вендоренного в пакет.
SVG-выход MUST NOT ссылаться на внешние ресурсы.

#### Scenario: Офлайн-сборка
- **WHEN** проект с `.wireflow.json` собирается без доступа к сети
- **THEN** диаграмма рендерится, SVG не содержит ссылок на внешние адреса

### Requirement: Ошибки и предупреждения wireflow

Невалидная структура файла (узел без `id` или `position`, ребро на несуществующий узел,
`parentId` на несуществующую группу) MUST давать ошибку с именем файла и идентификатором
элемента: для файла дерева — падение сборки, для диаграммы плагина — заглушка. Неизвестный
шаблон экрана MUST давать предупреждение и карточку-заглушку с id шаблона, не ошибку.

#### Scenario: Ребро на несуществующий узел
- **WHEN** ребро ссылается на `target: "x9"`, которого нет среди узлов
- **THEN** сборка прерывается ошибкой с именем файла и id ребра

#### Scenario: Неизвестный шаблон
- **WHEN** карточка ссылается на `graphicId`, которого нет в вендоренном каталоге
- **THEN** в логе предупреждение с файлом и id шаблона, на месте картинки — заглушка, сборка проходит

### Requirement: Детерминированный рендер wireflow

Повторный рендер одного файла MUST давать байт-в-байт одинаковый SVG независимо от машины:
метрики текста — по вендорному шрифту, порядок элементов — по порядку в файле, идентификаторы
внутри SVG — производные от содержимого, без случайных значений.

#### Scenario: Повторный рендер
- **WHEN** один и тот же `.wireflow.json` рендерится дважды на разных машинах
- **THEN** SVG-выходы совпадают байт-в-байт

### Requirement: Проверка wireflow командой check

`c4builder check` SHALL принимать файлы `.wireflow.json` и `wireflow.json`, выполнять ту же
проверку и рендер в памяти, что и сборка, и выводить ошибки в формате `✗ <файл>: <проблема>`,
а предупреждения — `⚠ <файл>: <проблема>`. Код выхода MUST быть 1 при ошибке и 0 при одних
предупреждениях.

#### Scenario: Валидный файл
- **WHEN** выполняется `c4builder check flow.wireflow.json` для корректного файла
- **THEN** код выхода 0

#### Scenario: Ошибка структуры
- **WHEN** файл содержит ребро на несуществующий узел
- **THEN** выводится `✗ flow.wireflow.json: …` с id ребра, код выхода 1

### Requirement: Кэш wireflow-диаграмм учитывает версию каталога шаблонов

Ключ кэша wireflow-диаграммы MUST включать версию вендоренного каталога шаблонов, формат вывода
и шрифт. Обновление каталога MUST перерисовывать wireflow-диаграммы при следующей сборке.

#### Scenario: Обновлён каталог шаблонов
- **WHEN** после обновления вендоренного каталога проект собирается с кэшем прошлой сборки
- **THEN** wireflow-диаграммы перерендериваются, остальные берутся из кэша
