# cli-help Specification

## Purpose
Справка CLI: общая (`c4builder --help`) и по отдельной команде (`c4builder <command> --help`,
`c4builder help <command>`) — чтобы человек и агент видели опции, формат вывода и коды возврата
именно той команды, которую запускают.

## Requirements

### Requirement: Справка по команде
`c4builder <command> --help`, `c4builder <command> -h` и `c4builder help <command>` SHALL печатать в stdout справку этой команды и завершаться с кодом 0 для каждой позиционной команды CLI. Справка MUST содержать назначение команды, строку использования с аргументами и опции команды. Опции, относящиеся только к другим командам, MUST NOT печататься.

#### Scenario: Справка check без чужих флагов
- **WHEN** выполняется `c4builder check --help`
- **THEN** печатается справка `check` со строкой `Usage: c4builder check <files...>`, в ней нет `--wait`, `--as`, `--force`, `--name`, `--open-change`, код возврата 0

#### Scenario: Справка feedback
- **WHEN** выполняется `c4builder feedback -h`
- **THEN** справка содержит `--wait`, `--as <name>` и `-p, --port <n>` и не содержит `--force` и `--open-change`

#### Scenario: Команда help
- **WHEN** выполняется `c4builder help jre`
- **THEN** вывод совпадает с выводом `c4builder jre --help`

#### Scenario: Аргументы команды не мешают справке
- **WHEN** выполняется `c4builder check bad.puml --help` или `c4builder jre install --help`
- **THEN** печатается справка команды, файл не проверяется, JRE не скачивается, код возврата 0

### Requirement: Формат вывода и коды возврата в справке команды
Справка команды, у которой есть машиночитаемый вывод или коды возврата, отличные от «0 — успех, 1 — ошибка», SHALL описывать формат вывода и каждый код возврата. Справка MUST содержать хотя бы один пример запуска. Тексты справки MUST быть на английском.

#### Scenario: Формат check
- **WHEN** выполняется `c4builder check --help`
- **THEN** справка описывает строки `✓ <file>` и `✗ <file>: …` (с `line <N>` для `.puml`) и коды `0` и `1`

#### Scenario: Код 2 у feedback
- **WHEN** выполняется `c4builder feedback --help`
- **THEN** справка описывает, что пачка замечаний печатается в stdout, и коды возврата `0`, `1` (нет сервера или агентский режим выключен) и `2` (не задан или неверен `--as`)

#### Scenario: Формат doctor
- **WHEN** выполняется `c4builder doctor --help`
- **THEN** справка перечисляет группы проверок, описывает `--json` и коды `0`, `1` (ошибки, с `--strict` — и предупреждения) и `2` (неизвестная группа)

### Requirement: Общая справка
`c4builder --help`, `c4builder -h` и `c4builder help` SHALL печатать в stdout общую справку и завершаться с кодом 0. Она MUST содержать строку `Usage: c4builder`, назначение запуска без команды (сборка проекта), список позиционных команд с кратким описанием, глобальные опции (`-c, --config-file`, `-w, --watch`, `-p, --port`, `--system-fonts`, `-V, --version`, `-h, --help`) и подсказку `c4builder <command> --help`. Опции, относящиеся только к одной команде, MUST NOT печататься.

#### Scenario: Состав общей справки
- **WHEN** выполняется `c4builder --help`
- **THEN** печатаются все позиционные команды и глобальные опции, нет `--wait`, `--as`, `--force`, `--name`, `--yes`, `--open-change`, `--agent`, `--json`, а также флаговых алиасов `--site`, `--new`, `--config`, `--list`, `--reset`, `--docs`

### Requirement: Каноническая форма команд в справке
Справка SHALL показывать команды только в позиционной форме (`site`, `new`, `config`, `list`, `reset`, `docs`). Флаговые формы `--site`, `--new`, `--config`, `--list`, `--reset`, `--docs` MUST продолжать работать как раньше.

#### Scenario: Флаговый алиас работает
- **WHEN** в пустом каталоге выполняется `c4builder --new --name demo -y`
- **THEN** проект создаётся так же, как `c4builder new --name demo -y`, хотя `--new` в справке не упоминается

### Requirement: Справка без побочных эффектов
Любая форма справки MUST NOT создавать файлов, читать или менять конфиг проекта, запускать мастер настройки, сборку, сеть или проверку новой версии. Справка MUST работать вне проекта и без терминала. Справка для неизвестной команды MUST завершаться ошибкой о неизвестной команде с ненулевым кодом.

#### Scenario: Справка в пустом каталоге без терминала
- **WHEN** в пустом каталоге без TTY выполняется `c4builder site --help`
- **THEN** печатается справка `site`, код возврата 0, каталог остаётся пустым

#### Scenario: Справка неизвестной команды
- **WHEN** выполняется `c4builder serve --help` или `c4builder help serve`
- **THEN** печатается сообщение о неизвестной команде `serve` со списком команд, код возврата 1
