# cli-commands Specification

## Purpose
Позиционные подкоманды CLI (`check`, `jre`, `site`, `new`, `config`) как синонимы флагов и отказ на неизвестную команду вместо молчаливой сборки.

## Requirements

### Requirement: Позиционные подкоманды CLI
CLI SHALL принимать позиционные подкоманды `check`, `jre`, `site`, `new` и `config`. `c4builder new` MUST вести себя так же, как `c4builder --new`, а `c4builder config` — как `c4builder --config`, включая сочетание с остальными флагами (`--name`, `-y`). Первый позиционный аргумент, не входящий в этот список, MUST приводить к сообщению об неизвестной команде со списком поддерживаемых и ненулевому коду возврата, без запуска сборки и без интерактивных вопросов.

#### Scenario: Позиционная команда создания проекта
- **WHEN** в пустом каталоге выполняется `c4builder new --name demo -y`
- **THEN** проект `demo` создаётся так же, как командой `c4builder --new --name demo -y`, процесс завершается с кодом 0

#### Scenario: Позиционная команда настройки
- **WHEN** в каталоге проекта выполняется `c4builder config`
- **THEN** запускается мастер настройки, как при `c4builder --config`

#### Scenario: Опечатка в команде
- **WHEN** выполняется `c4builder nwe`
- **THEN** печатается сообщение о неизвестной команде `nwe` со списком поддерживаемых, процесс завершается с ненулевым кодом, сборка не запускается
