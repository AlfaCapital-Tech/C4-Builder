# site-comments Specification

## Purpose
Вопросы к странице сайта прямо из браузера в `site -w`: выделенный текст и комментарий
дописываются в раздел вопросов исходного `.md` страницы, цитаты подсвечиваются на странице,
вопрос удаляется кнопкой. Только dev-сервер — в выходы сборки ничего не попадает.

## Requirements

### Requirement: Комментарий к выделенному тексту
В режиме `c4builder site -w` страница сайта SHALL позволять выделить фрагмент текста и отправить к нему вопрос. Элементы управления и обработчик MUST присутствовать только в ответах dev-сервера с `-w`; файлы сборки (`dist`) MUST NOT их содержать.

#### Scenario: Кнопка у выделения
- **WHEN** пользователь выделяет текст внутри содержимого страницы в `site -w`
- **THEN** у выделения появляется кнопка комментария; по ней открывается поле ввода вопроса

#### Scenario: Сайт без watch
- **WHEN** сайт раздаётся `c4builder site` без `-w` или открыт со статического хостинга
- **THEN** кнопки нет, а `POST /__c4builder/comments` отвечает 404

### Requirement: Запись вопроса в исходный файл
Отправленный вопрос SHALL дописываться в раздел с заголовком из ключа `questionsHeading` (по умолчанию `Open questions`, сравнение без учёта регистра и уровня заголовка) исходного markdown-файла страницы: первого из файлов страницы, содержащего раздел, иначе первого файла. Если раздел содержит таблицу, вопрос MUST стать её строкой (при числовой первой колонке — со следующим номером, текст во второй колонке; строка-заглушка `...` заменяется); иначе — пунктом списка в конце раздела; при отсутствии раздела он SHALL быть создан в конце файла. Текст вопроса SHALL содержать комментарий, цитату выделения (до 200 символов) и заголовок раздела страницы, где сделано выделение.

#### Scenario: Таблица вопросов
- **WHEN** в `design.md` раздел `## Open questions` содержит таблицу `| # | Question | Owner |` со строками 1–2 и пользователь отправляет вопрос «Why?» к фрагменту «foo bar» под заголовком «Flow»
- **THEN** в таблицу добавляется строка `| 3 | Why? — «foo bar» (§ Flow) | |`, остальной текст файла не меняется

#### Scenario: Раздела нет
- **WHEN** в файле нет раздела с заголовком `questionsHeading`
- **THEN** в конец файла дописывается `## <questionsHeading>` и пункт списка с вопросом

#### Scenario: Страница без исходника
- **WHEN** вопрос отправлен со страницы, собранной без исходных файлов (сводка, индекс)
- **THEN** сервер отвечает 404 с сообщением, файлы не меняются

### Requirement: Пересборка после записи
После записи вопроса watch SHALL пересобрать сайт, а открытая страница — перезагрузиться с сохранением позиции прокрутки, как при любом изменении исходников.

#### Scenario: Вопрос виден после отправки
- **WHEN** вопрос записан в файл
- **THEN** после перезагрузки страница показывает его в разделе вопросов

### Requirement: Защита от чужого источника
Обработчик MUST принимать запрос только с локальным `Host` (`127.0.0.1` или `localhost` с портом сервера) и заголовком `Origin`, совпадающим с адресом самого сервера; иначе SHALL отвечать 403 и MUST NOT менять файлы. Запись MUST выполняться только в файлы, из которых собрана страница, внутри текущего каталога проекта.

#### Scenario: Запрос с другого сайта
- **WHEN** на `POST /__c4builder/comments` приходит запрос с `Origin` другого хоста или без него
- **THEN** ответ 403, файлы не изменены

#### Scenario: DNS rebinding
- **WHEN** запрос приходит с согласованными `Host` и `Origin` чужого домена, перепривязанного на 127.0.0.1
- **THEN** ответ 403, файлы не изменены

### Requirement: Удаление вопроса со страницы
В `site -w` у каждой строки таблицы и пункта списка раздела вопросов SHALL быть кнопка удаления; удаление выполняется одним нажатием, без подтверждения. Сервер SHALL удалить из исходного файла строку, найденную по номеру (числовая таблица) и тексту вопроса, как он виден на странице, иначе только по тексту. Номера остальных строк MUST NOT меняться. Если строка не найдена, сервер SHALL ответить 404, если подходит несколько строк — 409, и в обоих случаях MUST NOT менять файл.

#### Scenario: Удаление строки таблицы
- **WHEN** пользователь нажимает «×» у строки `| 2 | Why? — «foo» (§ Flow) | |` таблицы с строками 1–3
- **THEN** строка 2 удалена из файла, строки 1 и 3 сохраняют номера, страница перезагружается без неё

#### Scenario: Страница устарела
- **WHEN** строка с таким текстом в файле уже отсутствует
- **THEN** ответ 404 с подсказкой перезагрузить страницу, файл не изменён
