# project-template

## Purpose

Требования к демо-проекту, создаваемому командой `c4builder new`: офлайн-сборка, stdlib-инклюды C4-PlantUML, демонстрация локальных `.iuml` и кириллицы.

## Requirements

### Requirement: Демо-проект собирается офлайн
Проект, созданный `c4builder new`, SHALL собираться без доступа в интернет: рендер всех диаграмм шаблона (PlantUML, D2, BPMN) MUST выполняться локальными движками без сетевых обращений.

#### Scenario: Сборка нового проекта без сети
- **WHEN** проект создан из шаблона и `c4builder` запущен в окружении без доступа в интернет
- **THEN** сборка завершается успешно и все диаграммы шаблона отрендерены

### Requirement: Диаграммы шаблона используют stdlib-инклюды
Все `.puml` шаблона MUST подключать C4-PlantUML через stdlib (`!include <C4/...>`); http(s)-инклюды в шаблоне и в VS Code-сниппетах (`C4.code-snippets`) MUST отсутствовать.

#### Scenario: Проверка инклюдов шаблона
- **WHEN** просматриваются `.puml` шаблона и файл сниппетов
- **THEN** ни один не содержит `!include http`, а C4-диаграммы используют `!include <C4/...>`

### Requirement: Шаблон демонстрирует локальный .iuml
Шаблон MUST содержать общий `.iuml`-файл (стили/тема), подключаемый минимум из двух диаграмм относительным `!include`.

#### Scenario: Сборка диаграмм с .iuml-инклюдом
- **WHEN** собирается новый проект из шаблона
- **THEN** диаграммы, подключающие общий `.iuml`, рендерятся успешно с применёнными стилями

### Requirement: Шаблон демонстрирует кириллицу
Шаблон MUST содержать страницу с русским md-текстом и диаграмму с кириллическими подписями элементов.

#### Scenario: Кириллица в собранном выходе
- **WHEN** собирается новый проект из шаблона
- **THEN** кириллический текст присутствует без искажений в выходных md и в SVG кириллической диаграммы

### Requirement: Шаблон содержит инструкции для агента
Проект, созданный `c4builder --new`, SHALL содержать в корне файл `AGENTS.md` на английском языке, который описывает: сборку (`c4builder`), проверку отдельных диаграмм (`c4builder check <file...>`), живой просмотр (`c4builder --site -w`), расположение исходников (`src/`) и конвенции диаграмм (stdlib-инклюды `<C4/...>`, общий `.iuml`, офлайн-рендер), а также команду установки скиллов `npx skills add AlfaCapital-Tech/C4-Builder/skills`. `AGENTS.md` MUST NOT попадать в выходы сборки (сайт, markdown, complete-markdown).

#### Scenario: AGENTS.md в новом проекте
- **WHEN** проект создан командой `c4builder --new --name demo -y`
- **THEN** в каталоге `demo/` есть `AGENTS.md` с командами `c4builder`, `c4builder check` и `npx skills add AlfaCapital-Tech/C4-Builder/skills`

#### Scenario: AGENTS.md не попадает в выходы
- **WHEN** новый проект собран командой `c4builder`
- **THEN** в каталоге выходов нет файла `AGENTS.md`, а сгенерированные страницы не содержат его текста

### Requirement: Шаблон демонстрирует BPMN-процесс
Шаблон MUST содержать раздел с `.bpmn`-диаграммой без координат (без BPMN DI), с несколькими пулами, дорожками, событием-таймером и message flow, с кириллическими подписями, и md-страницей, поясняющей, что агент пишет только семантическую часть, а раскладку делает сборка.

#### Scenario: BPMN-пример в новом проекте
- **WHEN** собирается новый проект из шаблона
- **THEN** BPMN-диаграмма раздела отрендерена с горизонтальными пулами и дорожками, а `c4builder check` для её файла завершается с кодом 0
