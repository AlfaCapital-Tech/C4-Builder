# offline-site Specification

## Purpose
Сайт, собранный c4builder, открывается и работает без интернета и ничего не отправляет за
пределы своего адреса: ни шрифты, ни emoji, ни исходники диаграмм не уходят на внешние сервисы.

## Requirements

### Requirement: Сайт по умолчанию не обращается к внешним доменам
Собранный docsify-сайт при встроенном шаблоне и теме по умолчанию (`webTheme: vendor/vue.css`) MUST NOT содержать в `index.html`, подключаемых CSS и сгенерированных страницах ссылок на ресурсы внешних доменов (`http://`, `https://`, `//host`), загружаемых браузером автоматически: шрифты, стили, скрипты, изображения. Встроенный шаблон MUST NOT подключать клиентский рендер PlantUML и MUST включать отображение emoji родными символами вместо картинок. Ссылки, которые пользователь сам написал в тексте страниц (обычные гиперссылки), этим требованием не затрагиваются. Не затрагиваются им и страницы встроенного плагина, назначение которого — эмбед внешнего сервиса (`figma`), когда пользователь явно подключил его в `plugins`: такие страницы MAY загружать эмбед этого сервиса, остальные страницы, `index.html` и CSS остаются под требованием.

#### Scenario: Шаблонный проект без внешних ресурсов
- **WHEN** проект создан `c4builder --new --name demo -y` и собран `c4builder`
- **THEN** в `index.html`, `vendor/*.css` и `.md`-страницах выхода нет адресов внешних доменов, кроме гиперссылок из исходного текста

#### Scenario: Тема без внешних шрифтов
- **WHEN** сайт собран с `webTheme: vendor/vue.css`
- **THEN** скопированный в выход `vendor/vue.css` не содержит `@import` внешних шрифтов, а вендорный файл пакета не изменён

#### Scenario: Emoji без картинок
- **WHEN** страница содержит `:smile:`
- **THEN** сайт показывает символ emoji, не запрашивая изображений с внешних адресов

#### Scenario: Совместимость пользовательского шаблона
- **WHEN** пользовательский `docsifyTemplate` подключает `vendor/docsify-plantuml.min.js`
- **THEN** файл присутствует в выходе (нет 404), сборка проходит, а опции шаблона содержат включённые родные emoji

#### Scenario: Ассеты сворачивания sidebar локальны
- **WHEN** сайт собран с `sidebarCollapse` по умолчанию
- **THEN** скрипт и стиль сворачивания лежат в `vendor/` выхода, подключены относительными путями и не содержат адресов внешних доменов

#### Scenario: Подключённый плагин figma
- **WHEN** в `plugins` подключён `figma`
- **THEN** внешний адрес `embed.figma.com` есть только на страницах раздела плагина, а `index.html`, CSS и прочие страницы внешних адресов не содержат

### Requirement: Блоки PlantUML в страницах рендерятся при сборке
Fenced-блоки с языком `plantuml` в markdown-страницах проекта SHALL извлекаться в диаграммы страницы и рендериться тем же движком и в том же `diagramFormat`, что и файлы `.puml`. На месте блока MUST стоять изображение. Исходный текст блока MUST NOT оставаться в выходах (сайт, markdown, complete-markdown), чтобы клиентский рендер в браузере не мог его отправить. Блоки `mermaid` рендерятся при сборке по правилам capability `mermaid-diagrams`. Блоки с другими языками (`puml`, `d2`, прочие) MUST оставаться кодом без изменений. Синтаксическая ошибка в блоке MUST NOT ронять сборку: на месте блока — заглушка, в логе — предупреждение с именем исходного файла.

#### Scenario: Блок plantuml становится картинкой
- **WHEN** `src/README.md` содержит блок ```` ```plantuml ```` с C4-диаграммой на stdlib
- **THEN** в выходах на его месте изображение, отрендеренное локально, и нет текста блока

#### Scenario: Блок puml остаётся кодом
- **WHEN** страница содержит блок ```` ```puml ```` с примером диаграммы
- **THEN** в выходах он остаётся блоком кода с исходным текстом

#### Scenario: Блок mermaid не остаётся кодом
- **WHEN** страница содержит блок ```` ```mermaid ````
- **THEN** в выходах на его месте изображение, отрендеренное локально, а сайт не подключает клиентский рендер mermaid

#### Scenario: Ошибка в блоке
- **WHEN** блок ```` ```plantuml ```` не компилируется
- **THEN** сборка завершается с кодом 0, на месте блока заглушка, предупреждение называет исходный `.md`-файл

#### Scenario: Пользовательский шаблон с клиентским рендером
- **WHEN** проект с пользовательским `docsifyTemplate`, подключающим `docsify-plantuml`, содержит блок ```` ```plantuml ```` в странице
- **THEN** выходная страница не содержит блока `plantuml`, и браузер не обращается к сервису рендера

### Requirement: Автоматическая проверка офлайн-сайта
Тесты SHALL собирать шаблонный проект и проверять отсутствие адресов внешних доменов в `index.html`, CSS и страницах выхода по правилу требования «Сайт по умолчанию не обращается к внешним доменам». Найденный адрес MUST называться в сообщении теста вместе с файлом.

#### Scenario: Регресс ловится тестом
- **WHEN** во встроенный шаблон добавлен `<script src="https://cdn.example/x.js">`
- **THEN** тест падает с сообщением, называющим `index.html` и адрес
