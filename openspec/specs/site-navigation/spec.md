# site-navigation Specification

## Purpose
Навигация по собранному docsify-сайту: sidebar с разделами, которые сворачиваются и
раскрываются, чтобы большое дерево проекта оставалось обозримым.

## Requirements

### Requirement: Sidebar сворачивает разделы
Собранный сайт SHALL показывать в sidebar раскрытыми только разделы первого уровня и путь к
текущей странице; остальные вложенные списки свёрнуты. Клик по разделу MUST раскрывать его, а
повторный — сворачивать; переход на страницу MUST раскрывать её путь. Ссылки и порядок пунктов
sidebar не меняются.

#### Scenario: Открытие страницы из глубины дерева
- **WHEN** открыта страница `A/B/C`
- **THEN** в sidebar раскрыты `A` и `A/B`, остальные разделы `A` и соседи `A` свёрнуты

#### Scenario: Сворачивание кликом
- **WHEN** читатель кликает по раскрытому разделу
- **THEN** его вложенный список скрывается, текущая страница не меняется

### Requirement: Ключ sidebarCollapse
`.c4builder` SHALL принимать булев ключ `sidebarCollapse` (по умолчанию `true`). При `false`
sidebar MUST быть полностью развёрнут, как без плагина сворачивания, а его ассеты MUST NOT
подключаться в `index.html`. Отсутствие ключа в существующем конфиге MUST давать значение по
умолчанию без изменения остального поведения сборки.

#### Scenario: Отключение
- **WHEN** в `.c4builder` `sidebarCollapse: false`
- **THEN** `index.html` не содержит скрипта и стиля сворачивания, все уровни sidebar видны

#### Scenario: Старый конфиг без ключа
- **WHEN** проект собирается с `.c4builder`, где ключа нет
- **THEN** sidebar сворачивается, прочие выходы идентичны сборке с явным `sidebarCollapse: true`

### Requirement: Сворачивание работает с пользовательским шаблоном
Скрипт и стиль сворачивания SHALL подключаться пост-обработкой `index.html`, а уровень
раскрытия — через опции docsify. С пользовательским `docsifyTemplate`, выводящим переданные
опции в `window.$docsify`, сворачивание MUST работать без правки шаблона.

#### Scenario: Проект со своим шаблоном
- **WHEN** `docsifyTemplate` указывает на шаблон, который вставляет опции в `window.$docsify`
- **THEN** собранный `index.html` содержит скрипт и стиль сворачивания, sidebar сворачивается
