# Proposal

## Why

`c4builder check --help`, `c4builder feedback --help`, `c4builder jre --help` печатают одну и ту же
общую справку — около 30 флагов всех команд в одном списке (`--wait`, `--as` — только `feedback`,
`--force` — только `jre install`, `--name`, `-y` — только `new`, `--open-change`, `--agent` —
только `site`). У команды нет ни описания аргументов, ни формата вывода, ни кодов возврата.
Агент знакомится с командой именно через `<command> --help` и получает чужие флаги (issue #63).

## What Changes

- `c4builder <command> --help` (и `-h`) печатает справку **этой** команды: назначение, строку
  использования, свои опции и применимые к ней глобальные, формат вывода, коды возврата,
  1–2 примера. Код 0, без файлов, без чтения конфига проекта и без уведомления о новой версии.
- Новая команда `c4builder help [command]` — то же, что `c4builder [command] --help`.
- Общая справка `c4builder --help` — назначение запуска без команды (сборка), список команд
  и только глобальные опции: `-c, --config-file`, `-w, --watch`, `-p, --port`, `--system-fonts`,
  `-V`, `-h`; подсказка `c4builder <command> --help`. Опции отдельных команд в ней не печатаются.
- Каноническая форма в справке и документации — подкоманды. Флаговые формы `--site`, `--new`,
  `--config` остаются рабочими алиасами, но в справке не показываются.
- Для единообразия у флагов-команд `--list`, `--reset`, `--docs` появляются позиционные формы
  `c4builder list`, `c4builder reset`, `c4builder docs`; флаги остаются алиасами.
- Флаги по-прежнему принимаются любой командой: проверка «флаг не от этой команды» в change
  не входит — меняется только справка.

## Capabilities

### New Capabilities

- `cli-help`: справка CLI — общая и по команде (`--help`, `-h`, `help [command]`): состав,
  формат вывода и коды возврата в справке, отсутствие побочных эффектов.

### Modified Capabilities

- `cli-commands`: список позиционных подкоманд пополняется `list`, `reset`, `docs`, `help`;
  справочные команды без побочных эффектов — и в позиционной форме.
- `agent-skills`: флаги из скиллов сверяются с общей справкой и справками команд, а не только
  с `c4builder --help`.
- `cli-update`: уведомление о новой версии не печатают ни справка команды, ни `c4builder help`.

## Impact

- Код: `src/cli/dispatch.ts` (своя опция `-h, --help` вместо встроенной справки commander,
  позиционные `list`/`reset`/`docs`/`help`), новый модуль справки `src/cli/help.ts`;
  обработчик `--docs` (`src/cli/commands/help.ts`) переименовывается в `docs.ts`, чтобы не
  путать с новой справкой.
- Тесты: `test/cli-commands.test.mjs` (справка общая и по командам), `test/skills.test.mjs`
  (известные флаги — из всех справок).
- Документация: страница «CLI и конфигурация» (RU и EN), скиллы (`skills/*`,
  `template/AGENTS.md`) — каноническая форма `c4builder site`/`new`/`config`/`list`, упоминание
  `<command> --help`; `CHANGELOG.md`.
- Совместимость: флаговые формы и все флаги работают как раньше; меняется только текст
  `--help`. Скрипты, разбирающие вывод общей справки, увидят другой состав.
