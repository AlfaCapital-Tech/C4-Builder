# Spec Delta

## MODIFIED Requirements

### Requirement: Комментарий к выделенному тексту
В режиме `c4builder site -w` страница сайта SHALL позволять выделить фрагмент текста и отправить к нему вопрос. У выделения SHALL появляться кнопка **Question**, а в агентском режиме (capability `site-agent-feedback`) рядом с ней — кнопка **Feedback**; адресат виден до ввода текста. Поле ввода вопроса SHALL отправлять его кнопкой **Add question**. Элементы управления и обработчик MUST присутствовать только в ответах dev-сервера с `-w`; файлы сборки (`dist`) MUST NOT их содержать.

#### Scenario: Кнопка у выделения
- **WHEN** пользователь выделяет текст внутри содержимого страницы в `site -w` без агентского режима
- **THEN** у выделения появляется кнопка **Question**; по ней открывается поле ввода вопроса с кнопкой **Add question**

#### Scenario: Кнопки в агентском режиме
- **WHEN** пользователь выделяет текст в `site -w`, работающем в агентском режиме
- **THEN** у выделения две кнопки — **Feedback** и **Question**; **Question** работает так же, как без агентского режима

#### Scenario: Сайт без watch
- **WHEN** сайт раздаётся `c4builder site` без `-w` или открыт со статического хостинга
- **THEN** кнопки нет, а `POST /__c4builder/comments` отвечает 404
