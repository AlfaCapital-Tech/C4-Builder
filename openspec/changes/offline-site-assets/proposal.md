## Why

Контракт c4builder — «рендер только локальный, онлайн-сервисы не использовать», но
docsify-сайт, который он генерирует для любого пользователя, ходит во внешний мир прямо из
браузера читателя: вендорная тема `vue.css` начинается с `@import` Google Fonts, docsify
превращает `:emoji:` в картинки с `github.githubassets.com`, плагин `docsify-plantuml`
отправляет текст блоков ```` ```plantuml ```` со страниц на `www.plantuml.com` (утечка
содержимого диаграмм из корпсреды), а swagger-ui плагина `openapi` по умолчанию показывает
бейдж `validator.swagger.io` с адресом спеки. Нашли при сборке собственного сайта
документации — там это обойдено отдельным шаблоном `docs/docsify-template.mjs`; чинить нужно
в продукте, для всех.

## What Changes

- **Встроенный шаблон `index.html` без внешних ресурсов**: не подключает
  `docsify-plantuml`, включает родные emoji (`nativeEmoji`) вместо картинок GitHub.
  Параметр `nativeEmoji: true` передаётся в объекте опций шаблона, так что и
  пользовательские шаблоны, сериализующие опции в `window.$docsify`, получают его.
- **Тема без Google Fonts**: при копировании вендорных ассетов в выходной каталог из
  `vue.css` вырезается `@import` шрифтов (вендорный файл не меняется); шрифты —
  системный fallback из той же темы.
- **Блоки ```` ```plantuml ```` в markdown-страницах рендерятся при сборке** локальным
  движком (тот же экстрактор, что у плагина `openspec`, переносится в ядро): на месте блока —
  изображение, в выходах блока нет, так что клиентский `docsify-plantuml` (даже в
  пользовательском шаблоне вроде арх-репо) рендерить нечего. Другие языки
  (```` ```puml ````, ```` ```d2 ````) не трогаются — это принятая форма «показать исходник
  как код».
- **swagger-ui плагина `openapi` без внешнего валидатора** (`validatorUrl: null`).
- **Автотест «в собранном сайте нет внешних адресов»**: сканирует `index.html`, CSS и
  страницы собранного шаблонного проекта на `http(s)://` и `//host` вне allow-листа.
- `vendor/docsify-plantuml.min.js` по-прежнему копируется в выход: пользовательские шаблоны,
  которые его подключают, не получают 404.
- Сайт документации переходит на встроенный шаблон, его обход внешних ресурсов удаляется.

## Capabilities

### New Capabilities
- `offline-site`: собранный docsify-сайт при конфигурации по умолчанию не обращается к
  внешним доменам; ```` ```plantuml ````-блоки страниц рендерятся при сборке; автопроверка.

### Modified Capabilities
- `openapi-plugin`: страница спеки не обращается к внешнему валидатору swagger-ui.

## Impact

- `src/core/compose/docsify.template.ts`, `src/core/compose/markdown.ts` (опции шаблона,
  копирование вендора с правкой `vue.css`), `src/core/scan/tree.ts` (извлечение блоков
  страниц), перенос `src/plugins/openspec/fences.ts` в ядро, `src/plugins/openapi/index.ts`.
- Golden: меняются `index.html` и `vendor/vue.css` во всех эталонах — переснять осознанно.
- Арх-репо (свой `docsifyTemplate` с `docsify-plantuml`, `webTheme` → `vendor/vue.css`):
  правок не требует, утечка закрывается сборкой; блок ```` ```puml ```` в нём остаётся кодом.
- `docs/` сайта, `CHANGELOG.md`, скилл `c4builder` (раздел о диаграммах в страницах).
- Новых npm-зависимостей нет.
