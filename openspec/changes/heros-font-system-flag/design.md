# Design: heros-font-system-flag

## Context

Пин шрифта живёт в одной точке — `src/core/render/fonts.ts` (`FONTS_DIR`,
`DEFAULT_FONT_NAME = 'Liberation Sans'`) — и применяется в двух движках:

- JVM/PlantUML (`src/core/render/diagrams.ts`): `-Dsun.java2d.fontpath=prepend:`,
  `-SdefaultFontName`, `-SCircledCharacterFontName`;
- resvg (`src/core/render/pngraster.ts`): `fontDirs`, `defaultFontFamily`,
  `loadSystemFonts: false`.

Имя шрифта уже входит в ключ кеша рендера (`diagrams.ts`, `font=...`).
Golden-эталоны собраны под Liberation Sans. Обратная связь: вид диаграмм
изменился по сравнению с системным шрифтом (на Mac — Helvetica).

## Goals / Non-Goals

**Goals:**

- Дефолтный вид текста — метрический клон Helvetica (TeX Gyre Heros), детерминизм
  сохраняется.
- Явный откат на системные шрифты: ключ `useSystemFonts` в `.c4builder` +
  разовый CLI-флаг `--system-fonts`.
- Кеш не смешивает режимы; golden остаётся зелёным и детерминированным.

**Non-Goals:**

- Произвольный пользовательский шрифт (ключ `fontName` с путём к TTF) — не делаем,
  YAGNI; появится по реальному запросу.
- Детерминизм в режиме системных шрифтов — принципиально невозможен и не обещается.
- Смена шрифта ditaa — его движок берёт AWT-шрифт мимо опций пина (как сейчас).

## Decisions

1. **Шрифт — TeX Gyre Heros (GUST FL), 4 начертания OTF.**
   Альтернативы: Nimbus Sans — AGPL (лицензионное трение при вендоринге в npm),
   остаться на Liberation Sans — не закрывает фидбэк (клон Arial, не Helvetica).
   GUST FL разрешает распространение; происхождение и версия фиксируются в
   `vendor/fonts/README.md`.

2. **OTF (CFF-кривые) вшиваем как есть, без конвертации.**
   AWT читает CFF с Java 7, resvg — тоже. Проверка — прогон golden-matrix на
   linux/windows/macos. План Б (если AWT на какой-то ОС спотыкается):
   одноразовая конвертация OTF→TTF (fontforge) на этапе вендоринга; в репо
   в любом случае лежат готовые файлы, конвертация в сборку не входит.

3. **Опция — `useSystemFonts: boolean` (default `false`) в `.c4builder` +
   CLI-флаг `--system-fonts` как разовое переопределение (флаг сильнее конфига).**
   Конфиг — для репозиториев, где старый вид нужен постоянно (контракт arch не
   трогаем: отсутствие ключа = вендорный шрифт). Флаг — для «отрендерить разок
   как раньше» без правки конфига. Оба стоят копейки: bool в zod-схеме +
   `.option()` в commander.

4. **Механика отключения пина — просто не передавать его.**
   JVM: три шрифтовых аргумента не добавляются в argv → PlantUML ведёт себя как
   до ветки phoenix (системный fontconfig). resvg: `loadSystemFonts: true`, без
   `fontDirs`/`defaultFontFamily`. Никаких «пустых значений» и промежуточных
   абстракций — условное включение трёх строк в argv и одного поля опций.

5. **Ключ кеша: `font=<имя>` → в системном режиме `font=system`.**
   Механизм уже существует, меняется только значение — переключение режима
   автоматически промахивается мимо кеша другого режима. Версию схемы кеша
   поднимать не нужно.

6. **Golden — только вендорный шрифт.**
   Эталоны пересобираются один раз под Heros. `useSystemFonts` в golden-контуре
   не участвует: системные шрифты недетерминированы, их фиксация невозможна.
   Покрытие системного режима — unit-тест на argv/опции рендера (флаги шрифта
   отсутствуют), не пиксельная сверка.

## Risks / Trade-offs

- [CFF-шрифт не подхватится AWT на одной из ОС] → ловится golden-matrix до
  мержа; план Б — вендорим TTF-конвертацию (решение 2).
- [Имя семейства в name-таблице OTF не совпадёт с ожиданием AWT/resvg
  (`TeX Gyre Heros`)] → сверить `fc-scan`/метаданные при вендоринге; имя задаётся
  единственной константой `DEFAULT_FONT_NAME`.
- [В системном режиме на голой машине/в докере нет шрифтов → JVM logical font /
  пустой fontconfig] → это ожидаемое свойство режима «как раньше», фиксируем в
  README одним предложением; дефолт остаётся детерминированным.
- [Метрики Heros ≠ Liberation → у arch изменится геометрия всех диаграмм] →
  осознанное следствие фидбэка; ничего в конфиге arch менять не нужно.

## Migration Plan

1. Заменить файлы в `vendor/fonts/` + README (происхождение, лицензия GUST FL).
2. `DEFAULT_FONT_NAME` → `'TeX Gyre Heros'`; опция и флаг; условный пин.
3. Пересобрать golden-эталоны, прогнать golden-matrix на трёх ОС.
4. Откат — revert коммита: шрифт, эталоны и ключ кеша вернутся согласованно.

## Open Questions

Нет — дефолт-шрифт подтверждён пользователем (Heros, не JetBrains Mono: тот
моноширинный; JetBrains Sans — проприетарный, вендорить нельзя).
