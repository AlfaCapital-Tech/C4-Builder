# Spec Delta

## ADDED Requirements

### Requirement: Golden-тест покрывает BPMN-рендер
Golden-fixture SHALL включать `.bpmn`-диаграмму с collaboration из нескольких пулов, дорожками, промежуточным или граничным событием-таймером, message flow и кириллическими подписями. Golden-тест MUST сравнивать её SVG-выход (вариант `default`) и PNG-выход (вариант `embed-png`) с эталонами наравне с PlantUML и D2. Детерминизм обеспечивается вендорным шрифтом для метрик текста и точным пином версий пакетов раскладки и рендера.

#### Scenario: BPMN-диаграмма в fixture совпадает с эталоном
- **WHEN** golden-тест собирает fixture, содержащий `.bpmn`
- **THEN** её SVG (после нормализации) совпадает с закоммиченным эталоном

#### Scenario: Повторный прогон BPMN идентичен
- **WHEN** сборка fixture с `.bpmn` выполняется дважды
- **THEN** SVG-выход BPMN-диаграммы байт-в-байт совпадает между прогонами

#### Scenario: Обновление пакета раскладки ловится тестом
- **WHEN** версия пакета раскладки или рендера меняется и меняет координаты
- **THEN** golden-тест падает до явного переснятия эталона
