## MODIFIED Requirements

### Requirement: Комментарий к выделенному тексту
В режиме `c4builder site -w` страница сайта SHALL показывать у выделенного фрагмента текста кнопки по числу адресатов: **Comment** — комментарий людям строкой в журнал ревью (только с ключом `comments`) и, в агентском режиме (capability `site-agent-feedback`), **Tell agent** — замечание агенту. Без журнала и без агентского режима кнопок у выделения нет. Кнопка **Comment** SHALL открывать поле ввода с цитатой выделения и кнопкой **Add comment**. Элементы управления и обработчики MUST присутствовать только в ответах dev-сервера с `-w`; файлы сборки (`dist`) MUST NOT их содержать.

#### Scenario: Кнопка у выделения
- **WHEN** в `.c4builder` задан `comments`, агентского режима нет, и пользователь выделяет текст в `site -w`
- **THEN** у выделения одна кнопка **Comment**; по ней открывается поле ввода с кнопкой **Add comment**

#### Scenario: Кнопки в агентском режиме
- **WHEN** в `.c4builder` задан `comments`, а `site -w` работает в агентском режиме
- **THEN** у выделения две кнопки — **Tell agent** и **Comment**

#### Scenario: Ни журнала, ни агента
- **WHEN** ключа `comments` нет и агентского режима нет
- **THEN** при выделении текста кнопки не появляются

#### Scenario: Сайт без watch
- **WHEN** сайт раздаётся `c4builder site` без `-w` или открыт со статического хостинга
- **THEN** кнопок нет, а `POST /__c4builder/review-log` отвечает 404

### Requirement: Защита от чужого источника
Обработчики журнала ревью MUST принимать запрос только с локальным `Host` (`127.0.0.1` или `localhost` с портом сервера) и заголовком `Origin`, совпадающим с адресом самого сервера; иначе SHALL отвечать 403 и MUST NOT менять файлы. Запись MUST выполняться только в файл журнала внутри текущего каталога проекта.

#### Scenario: Запрос с другого сайта
- **WHEN** на `POST /__c4builder/review-log` приходит запрос с `Origin` другого хоста или без него
- **THEN** ответ 403, файлы не изменены

#### Scenario: DNS rebinding
- **WHEN** запрос приходит с согласованными `Host` и `Origin` чужого домена, перепривязанного на 127.0.0.1
- **THEN** ответ 403, файлы не изменены

## REMOVED Requirements

### Requirement: Запись вопроса в исходный файл
**Reason**: Кнопка **Question** дублировала журнал ревью — оба пишут текст людям в файл (#61).
**Migration**: Комментарии людям — кнопкой **Comment** в журнал (ключ `comments`); правки — кнопкой
**Tell agent**. Ключи `questions` и `questionsHeading` больше не читаются, уже записанные разделы
вопросов остаются в `.md` обычным текстом.

### Requirement: Пересборка после записи
**Reason**: Требование описывало запись вопроса, которой больше нет; пересборку после записи журнала
обеспечивает watch, как для любого изменения исходников.
**Migration**: Не требуется.

### Requirement: Удаление вопроса со страницы
**Reason**: Вопросов на странице больше нет; удаление строк журнала остаётся у журнала ревью.
**Migration**: Вопросы, записанные раньше, удаляются правкой `.md` вручную.

## ADDED Requirements

### Requirement: Ключ comments
Журнал для кнопки **Comment** SHALL настраиваться ключом `.c4builder` `comments` с полями `enabled`,
`file`, `heading`, `cells`, `author`. Прежний ключ `reviewLog` с теми же полями SHALL читаться как
синоним, если ключа `comments` нет; если заданы оба, SHALL действовать `comments`, а `reviewLog`
MUST NOT влиять на файл, раздел и ячейки журнала. Об устаревшем ключе сборка MUST NOT предупреждать.

#### Scenario: Новый ключ
- **WHEN** в `.c4builder` задан `"comments": { "file": "review.md", "heading": "Remarks" }`
- **THEN** в `site -w` у выделения есть кнопка **Comment**, комментарий дописывается в раздел `Remarks` ближайшего `review.md`

#### Scenario: Старый ключ reviewLog
- **WHEN** в `.c4builder` задан только `reviewLog` с файлом `review.md`
- **THEN** кнопка **Comment** работает так же, как с ключом `comments`, предупреждений нет

#### Scenario: Заданы оба ключа
- **WHEN** заданы `comments: { "file": "a.md" }` и `reviewLog: { "file": "b.md" }`
- **THEN** комментарии пишутся в `a.md`

### Requirement: Подписи кнопок у выделения
Подписи кнопок у выделения SHALL называть адресата и MUST NOT совпадать с подписями панели пачки
агенту. Ключ `buttons` SHALL задавать свои подписи — `agent` для **Tell agent**, `comment` для
**Comment** — на любом языке интерфейса. Если `buttons.comment` не задан, кнопку **Comment** SHALL
подписывать старый `reviewLog.label`, иначе словарь по языку.

#### Scenario: Своя подпись кнопки агенту
- **WHEN** в `.c4builder` задано `"buttons": { "agent": "Fix it" }`, интерфейс на русском
- **THEN** кнопка агенту у выделения подписана «Fix it»

#### Scenario: Старый reviewLog.label
- **WHEN** в `reviewLog` задан `label: "Журнал"`, ключа `buttons` нет
- **THEN** кнопка журнала у выделения подписана «Журнал»

#### Scenario: buttons побеждает label
- **WHEN** заданы `reviewLog.label: "Журнал"` и `buttons.comment: "Note"`
- **THEN** кнопка журнала у выделения подписана «Note»
