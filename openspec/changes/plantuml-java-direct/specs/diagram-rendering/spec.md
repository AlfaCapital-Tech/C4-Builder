# diagram-rendering

## ADDED Requirements

### Requirement: Диаграммы рендерятся без внешнего graphviz
Сборка SHALL рендерить PlantUML-диаграммы с использованием встроенного в PlantUML
Java-движка раскладки (Smetana, `-Playout=smetana`) и MUST NOT требовать наличия
внешнего graphviz/dot. Отсутствие или неработоспособность `dot` в системе MUST NOT
приводить к ошибке рендера.

#### Scenario: Рендер при отсутствующем graphviz
- **WHEN** выполняется сборка, а исполняемый файл `dot` в системе недоступен
- **THEN** все диаграммы (C4 context/container/component/deployment/dynamic, class,
  sequence) успешно рендерятся в SVG, а кириллица в выходе сохраняется

#### Scenario: dot не вызывается
- **WHEN** запущен рендер диаграмм
- **THEN** процесс сборки не порождает вызовов внешнего `dot`

### Requirement: Рендер вызывает java напрямую
Сборка SHALL запускать PlantUML прямым вызовом `java` с вендорным JAR, без
посреднической библиотеки `node-plantuml`. Источником данных MUST быть stdin/stdout
(pipe-режим), чтобы имя выходного файла определялось c4builder по имени `.puml`-файла,
а не по имени диаграммы из директивы `@startuml`.

#### Scenario: Имя выходного файла независимо от @startuml
- **WHEN** рендерится диаграмма, у которой в `@startuml <name>` задано имя, отличное
  от имени файла
- **THEN** выходной файл именуется по имени `.puml`-файла (как прежде), а не по `<name>`

#### Scenario: Локальные и stdlib-инклюды резолвятся
- **WHEN** рендерится диаграмма с `!include <C4/...>` (stdlib) и `!include ../styles.iuml`
  (локальный файл)
- **THEN** оба вида инклюдов резолвятся, диаграмма собирается корректно

### Requirement: Детерминированные метрики текста через вендорный шрифт
Ширина текста в SVG зависит от метрик шрифта, поэтому сборка SHALL использовать
шрифт, поставляемый в составе репозитория (`vendor/fonts/`), и задавать его как
шрифт диаграмм по умолчанию. Шрифт MUST физически предоставляться JVM (а не только
задаваться по имени), чтобы исключить молчаливый откат на системный шрифт.

#### Scenario: Рендер использует вендорный шрифт
- **WHEN** выполняется сборка на машине, где заданный шрифт не установлен системно
- **THEN** рендер использует шрифт из `vendor/fonts/`, а не системный fallback

#### Scenario: Повторяемость метрик
- **WHEN** одна и та же диаграмма рендерится дважды на одной машине
- **THEN** геометрия выходного SVG (координаты и `textLength`) байт-в-байт идентична
