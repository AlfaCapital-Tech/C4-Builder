# Tasks: jre-resolver

> Предусловие: выполняется ТОЛЬКО после `plantuml-java-direct` (там появилась точка
> вызова java). Независимо от `d2-backend`/`resvg-png`/`remove-pdf`.

## 1. Зависимости

- [x] 1.1 Добавить `tar` и `yauzl` в `dependencies`; зафиксировать (пин) версии

## 2. Модуль резолвера (`jre.js`)

- [x] 2.1 `resolveJava()` — приоритетная цепочка: системная → кеш → скачивание;
      возвращает абсолютный путь к бинарю `java`; первый годный источник выигрывает
- [x] 2.2 Детект системной: `JAVA_HOME/bin/java`, затем `PATH`; `java -version` → парс
      мажорной версии; годна при мажоре ≥ 17; отсутствие/ошибка запуска — переход к
      следующему источнику (не падение)
- [x] 2.3 Кеш: путь `~/.cache/c4builder/jre/temurin-21-<os>-<arch>/` (Windows —
      `%LOCALAPPDATA%`); валидность = наличие `bin/java`(`.exe`); битую установку
      перекачивать
- [x] 2.4 Загрузчик Adoptium: assets API (`/v3/assets/latest/21/hotspot?...image_type=jre&vendor=eclipse`)
      → `{ link, sha256 }`; скачать по link; сверить sha256 ДО распаковки; несовпадение
      → ошибка, кеш не заполнять
- [x] 2.5 Маппинг `process.platform`/`process.arch` → `os`/`arch` Adoptium; выбор
      формата архива (`tar.gz` linux/mac → `tar`, `zip` windows → `yauzl`); распаковка
      в кеш
- [x] 2.6 Понятная ошибка при полном провале цепочки (поставить JRE 17+ либо
      `c4builder jre install`), без сырого стектрейса spawn

## 3. Встраивание в `build.js`

- [x] 3.1 В `generateImages` резолвить `javaBin` один раз ПЕРЕД циклом, только если в
      дереве есть хотя бы одна `engine === 'plantuml'` диаграмма
- [x] 3.2 `renderDiagram` принимает `javaBin` в опциях; `spawn(javaBin, argv)` вместо
      `spawn('java', argv)`
- [x] 3.3 Проект без `.puml` (только `.d2`) → `resolveJava` не вызывается, скачивание
      не инициируется

## 4. CLI — прогрев

- [x] 4.1 Подкоманда `c4builder jre install`: резолвит/скачивает JRE в кеш заранее, без
      полной сборки; печатает путь и версию
- [x] 4.2 (open) Поведение при годной системной java: сообщать «скачивание не требуется»
      против флага `--force` (см. design Open Questions) — решено: дефолт сообщает,
      `--force` форсирует загрузку

## 5. Верификация

- [x] 5.1 Системная java 17+ есть → используется, скачивание не выполняется, сеть не
      задействуется
- [x] 5.2 Системной java нет → скачивается Temurin 21 JRE под текущую платформу, sha256
      совпадает, PlantUML-диаграммы рендерятся
- [x] 5.3 Второй прогон → java берётся из кеша, без сети
- [x] 5.4 Проект только из `.d2` → java не резолвится, скачивания нет
- [x] 5.5 Офлайн, нет системной java и пустой кеш → понятная ошибка с двумя действиями,
      D2-рендер (если есть) при этом работает
- [x] 5.6 `c4builder jre install` → JRE в кеше, последующая сборка не качает
- [x] 5.7 Golden CI (Temurin 21 через `setup-java`) зелёный: срабатывает ветка
      «системная годная», layout не меняется (golden red только на `class.svg` —
      предсуществующий дрейф glyph-рендера, воспроизводится без этого change)
- [x] 5.8 `openspec validate jre-resolver --strict` проходит
