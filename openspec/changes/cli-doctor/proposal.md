## Why

Диагностика c4builder размазана по трём местам и видит не всё (issue #68):

- скилл `c4builder-setup` — агент по шагам проверяет Node, версию, Java, пробную сборку;
- строка о скиллах в stderr при сборке и `site` под агентом — только версия главного скилла
  `c4builder`, только каталог текущего агента, выключается вместе с проверкой новой версии;
- `c4builder jre info`.

Не видно: остальные скиллы пакета, копии без отметки версии или с изменённым текстом, дубли
проектных скиллов со скиллами плагинов Claude Code, каталоги Codex, состояние порта. Человек и
агент собирают картину вручную, а коллега, у которого «не работает», не может одной командой
показать, что у него стоит.

## What Changes

- Новая подкоманда `c4builder doctor [group...]` — только чтение: группы проверок `env`,
  `skills`, `render`, `project`, `runtime`; у каждой проверки статус `ok | warn | error | skipped`
  и у проблемы — одна строка с командой-исправлением.
- Флаги: `--json` (стабильные id проверок), `-v` (пути и подробности), `--strict` (код 1 и на
  предупреждениях), `--full` (пробная сборка шаблонного проекта вместо крошечной диаграммы),
  `--offline` (без проверки новой версии).
- Группа `skills`: все скиллы пакета во всех каталогах Claude Code, Codex и `.agents`; версия,
  полнота набора, совпадение текста с пакетом, перекрытие личной копией, дубли со скиллами
  плагинов Claude Code (по возможности).
- Вывод без `-v` безопасно вставлять в issue: домашний каталог — `~`, значений переменных
  окружения нет.
- Скилл `c4builder-setup` начинается с `c4builder doctor`; строка о скиллах под агентом
  добавляет `c4builder doctor skills` для подробностей.

## Capabilities

### New Capabilities
- `cli-doctor`: команда `c4builder doctor` — группы и статусы проверок, коды возврата, `--json`,
  проверка скиллов, среды, пробного рендера, проекта и запуска, безопасный для публикации вывод.

### Modified Capabilities
- `cli-commands`: новая позиционная подкоманда `doctor`.
- `agent-skills`: `c4builder-setup` начинается с `c4builder doctor`; строка уведомления о
  скиллах ссылается на `c4builder doctor skills`.

## Impact

- Код: новый `src/cli/commands/doctor.ts`; `src/cli/dispatch.ts` (подкоманда, флаги, текст
  уведомления о скиллах); переиспользуются `detectAgent`, `stampIn`/`skillsNotice` из
  `commands/skills.ts`, `newestVersion`/`compareVersions`/`VIEW` из `update.ts`,
  `resolveJava`/`cachedJava`, `parseConfig`, движок `check`.
- Тесты: новый `test/cli-doctor.test.mjs`; `test/cli-skills.test.mjs` (текст уведомления),
  `COMMANDS` в `test/skills.test.mjs`.
- Скиллы: `skills/c4builder-setup`, `skills/c4builder` (раздел о строке про скиллы);
  `template/AGENTS.md`.
- Документация: «05 CLI и конфигурация», «08 Агенты» (RU/EN), CHANGELOG; шаблон issue на GitHub.
- Публичность: в артефактах, скиллах и выводе — никаких внутренних хостов, реестров и названий
  внутренних инструментов и маркетплейсов организации.
