## Why

При работе над сайтом документации и скиллами агенты нашли в CLI три дефекта, которые бьют
по главному сценарию «агент правит → `c4builder check` → сборка» и по доверию к справочным
командам:

- `c4builder check styles.iuml` падает на любой `.iuml` с макросами C4
  (`UpdateElementStyle`, `Person`…): библиотека проверяется включением в пустую диаграмму без
  C4-stdlib. Из-за этого `.iuml` исключён из pre-commit-хука на сайте, а скиллы и `AGENTS.md`
  учат обходному пути.
- `check` печатает `✗ file: строка N: …`, хотя `--help`, остальной вывод CLI и формат,
  который разбирают агенты и CI, — английские. Документация и скиллы вынуждены пояснять
  «`строка` means "line"».
- `c4builder --docs` (а также `--list` и `--reset`) в папке без проекта создаёт пустые
  `.c4builder` и `.c4builder.cache`: справочная команда оставляет мусор, а следующий
  `c4builder` в этой папке уже считает её проектом.

Плюс мелочь из переноса changelog: ссылки `#docker` и «Plugins» в `CHANGELOG.md` ведут на
разделы README, которых больше нет.

## What Changes

- **`check` для `.iuml`**: обёртка библиотеки подключает C4-stdlib перед самим файлом, так
  что `.iuml` с макросами C4 проверяется в том же контексте, в котором его используют
  диаграммы. Библиотеки без C4 проверяются как раньше.
- **Вывод `check` на английском и стабильного формата**: `✗ <file>: line <N>: <message>`,
  сообщения об использовании и неизвестном расширении — тоже на английском. Остальной
  русский вывод CLI вне скоупа (отдельная задача).
- **Справочные команды без побочных эффектов**: `--docs` не читает и не создаёт конфиг;
  `--list` и `--reset` в папке без `.c4builder` сообщают, что проекта нет, и ничего не
  создают (код 1 для `--list`/`--reset`, 0 для `--docs`).
- **`CHANGELOG.md`**: мёртвые ссылки на разделы README заменяются ссылками на страницы
  сайта в репозитории (`docs/en/src/…`).
- Актуализация: страницы сайта RU/EN, скилл `c4builder`, `template/AGENTS.md`, README
  (строка про `check`), pre-commit-хук снова включает `*.iuml`.

## Capabilities

### New Capabilities
- (нет)

### Modified Capabilities
- `cli-commands`: добавляются требования к `check` (формат вывода, проверка `.iuml` с C4)
  и к справочным командам (`--docs`, `--list`, `--reset` не создают файлов вне проекта).

## Impact

- `src/cli/commands/check.ts` — обёртка `.iuml`, английские сообщения.
- `src/cli/dispatch.ts` — `--docs` до создания `Configstore`; проверка наличия
  `.c4builder` для `--list`/`--reset`.
- Тесты: `test/check.test.mjs` (ожидания `строка` → `line`, новый кейс `.iuml` с C4),
  `test/cli-commands.test.mjs` (справочные команды в пустой папке).
- Документация: `docs/ru/src`, `docs/en/src` (страницы «Диаграммы», «Агенты», «CLI и
  конфигурация»), `skills/c4builder/SKILL.md`, `template/AGENTS.md`, `README.MD`,
  `CHANGELOG.md`.
- Поведение сборки и golden-эталоны не меняются; новых зависимостей нет.
- Совместимость: скрипты, которые грепают `строка` в выводе `check`, перестанут совпадать —
  формат документирован как `line N`, строка в changelog об этом.
