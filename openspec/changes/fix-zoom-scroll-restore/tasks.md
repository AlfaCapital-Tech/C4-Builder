## 3. Правки по code-review: причина сброса, history-режим, мгновенный возврат

- [x] 3.1 `DIAGRAM_ZOOM_JS`, стиль блокировки: `html.c4-zoom-open{overflow:hidden}` и
  `html.c4-zoom-open body{overflow:visible}` вместо `overflow:hidden` на обоих (design, решение 2).
  Явный возврат позиции оставить страховкой. Проверка: в Chromium, Firefox и WebKit (Playwright,
  `docs/ru`, окно 1280 и 600 px) `scrollY` под открытым просмотром прежний; `PageDown`, пробел,
  `End` и колесо над панелью его не меняют; после закрытия позиция прежняя. `body{height:auto}`
  проверен и не помогает (`scrollY` под просмотром 0).
- [x] 3.2 Живая перезагрузка при открытом просмотре: сниппет `src/cli/commands/site.ts` сохраняет
  `window.scrollY` — после 3.1 он верный, сниппет не меняется. Проверка: `scrollY` под открытым
  просмотром равен позиции до открытия (3.1).
- [x] 3.3 «Назад»/«Вперёд» по истории того же документа при открытом просмотре даёт позицию из
  истории. Проверка: в трёх движках после «Назад» — позиция записи истории, а не 0 и не позиция
  открытия; со старым стилем Firefox давал 0.
