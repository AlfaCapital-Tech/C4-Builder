# Spec Delta

## MODIFIED Requirements

### Requirement: Минимальная поддерживаемая версия Node зафиксирована
`package.json` MUST декларировать `engines.node: ">=22.17"`. Код и рантайм-зависимости MUST NOT требовать возможностей Node, отсутствующих в 22.17; опциональные зависимости, загружаемые только для отдельных движков рендера, MUST быть совместимы с этой границей или давать понятную ошибку с требуемой версией Node.

#### Scenario: Установка на устаревшем Node
- **WHEN** пакет устанавливается на Node ниже 22.17 (в том числе Node 20)
- **THEN** npm сообщает о несовместимости engines (предупреждение, либо отказ при engine-strict)

#### Scenario: Работа на минимальной версии
- **WHEN** CLI запускается на Node 22.17
- **THEN** сборка шаблонного проекта и `c4builder check` выполняются без ошибок и без предупреждений об экспериментальных API Node
