# Spec Delta

## ADDED Requirements

### Requirement: Диаграммы рендерятся только локально
Все диаграммы проекта (файлы `.puml`, `.d2`, `.bpmn`, `.mmd`, wireflow и fenced-блоки страниц) SHALL рендериться при сборке локальными движками. Исходный текст диаграммы MUST NOT попадать в адреса внешних сервисов рендера ни в одном выходе (сайт, markdown, complete-markdown), и никакой ключ `.c4builder` MUST NOT включать такой режим. Мастер настройки MUST NOT спрашивать адрес сервера рендера или выбор между локальным и онлайн-рендером.

#### Scenario: PlantUML-файл в выходе — локальная картинка
- **WHEN** проект с `context.puml` собран с конфигом по умолчанию
- **THEN** в выходах на месте диаграммы — ссылка на локальный файл (`context.svg`) или встроенный SVG, адресов `plantuml.com` и других серверов рендера нет

#### Scenario: Мастер не спрашивает про сервер рендера
- **WHEN** запускается `c4builder config` для проекта
- **THEN** среди вопросов мастера нет адреса сервера PlantUML и пункта о локальной генерации картинок

#### Scenario: Конфиг без ключей онлайн-рендера собирается без мастера
- **WHEN** `.c4builder` заполнен, кроме `plantumlServerUrl` и `generateLocalImages`, а сборка запущена без терминала
- **THEN** сборка проходит без мастера, а `c4builder doctor` не называет эти ключи недостающими

#### Scenario: Новый проект без ключей онлайн-рендера
- **WHEN** проект создан `c4builder --new --name demo -y`
- **THEN** его `.c4builder` не содержит `plantumlServerUrl` и `generateLocalImages`

### Requirement: Ключи удалённого онлайн-рендера в старом конфиге
`.c4builder` с `generateLocalImages: false` SHALL собираться локальным рендером с кодом 0 и предупреждением, которое называет `generateLocalImages` и `plantumlServerUrl` и советует удалить их из `.c4builder`. `generateLocalImages: true` и любое значение `plantumlServerUrl` MUST игнорироваться без предупреждения. Сборка MUST NOT изменять `.c4builder`.

#### Scenario: Старый конфиг с выключенной локальной генерацией
- **WHEN** `.c4builder` содержит `"generateLocalImages": false` и `"plantumlServerUrl": "https://www.plantuml.com/plantuml"`, а проект содержит `.puml`
- **THEN** сборка завершается с кодом 0, диаграммы отрендерены локально, в выходах нет адреса сервера, в логе — предупреждение с именами обоих ключей, а `.c4builder` не изменён

#### Scenario: Ключи со значениями по умолчанию
- **WHEN** `.c4builder` содержит `"generateLocalImages": true` и `"plantumlServerUrl": "https://www.plantuml.com/plantuml"`
- **THEN** сборка проходит без предупреждения об этих ключах

#### Scenario: Проект с D2 и выключенной локальной генерацией
- **WHEN** `.c4builder` содержит `"generateLocalImages": false`, а проект содержит `.d2`-диаграмму
- **THEN** сборка не падает, D2-диаграмма отрендерена локально, в логе — предупреждение о ключах

## MODIFIED Requirements

### Requirement: Сайт по умолчанию не обращается к внешним доменам
Собранный docsify-сайт при встроенном шаблоне и теме по умолчанию (`webTheme: vendor/vue.css`) MUST NOT содержать в `index.html`, подключаемых CSS и сгенерированных страницах ссылок на ресурсы внешних доменов (`http://`, `https://`, `//host`), загружаемых браузером автоматически: шрифты, стили, скрипты, изображения. Встроенный шаблон MUST NOT подключать клиентский рендер PlantUML и MUST включать отображение emoji родными символами вместо картинок. Клиентский рендер PlantUML MUST NOT поставляться в составе пакета и копироваться в выход; пользовательский `docsifyTemplate`, который его подключает, MUST давать предупреждение, не роняя сборку. Ссылки, которые пользователь сам написал в тексте страниц (обычные гиперссылки), этим требованием не затрагиваются. Не затрагиваются им и эмбеды встроенного плагина, назначение которого — эмбед внешнего сервиса (`figma`), когда пользователь явно подключил его в `plugins`: страницы раздела плагина и страницы, где пользователь поставил картинку-ссылку на этот сервис, MAY загружать его эмбед; остальные страницы, `index.html` и CSS остаются под требованием.

#### Scenario: Шаблонный проект без внешних ресурсов
- **WHEN** проект создан `c4builder --new --name demo -y` и собран `c4builder`
- **THEN** в `index.html`, `vendor/*.css` и `.md`-страницах выхода нет адресов внешних доменов, кроме гиперссылок из исходного текста

#### Scenario: Тема без внешних шрифтов
- **WHEN** сайт собран с `webTheme: vendor/vue.css`
- **THEN** скопированный в выход `vendor/vue.css` не содержит `@import` внешних шрифтов, а вендорный файл пакета не изменён

#### Scenario: Emoji без картинок
- **WHEN** страница содержит `:smile:`
- **THEN** сайт показывает символ emoji, не запрашивая изображений с внешних адресов

#### Scenario: Совместимость пользовательского шаблона
- **WHEN** пользовательский `docsifyTemplate` подключает `vendor/docsify-plantuml.min.js`
- **THEN** сборка проходит с кодом 0 и предупреждением, что клиентский рендер PlantUML больше не поставляется, файла `docsify-plantuml.min.js` в выходе нет, а опции шаблона содержат включённые родные emoji

#### Scenario: Ассеты сворачивания sidebar локальны
- **WHEN** сайт собран с `sidebarCollapse` по умолчанию
- **THEN** скрипт и стиль сворачивания лежат в `vendor/` выхода, подключены относительными путями и не содержат адресов внешних доменов

#### Scenario: Подключённый плагин figma
- **WHEN** в `plugins` подключён `figma`
- **THEN** внешний адрес `embed.figma.com` есть только на страницах раздела плагина и страницах с картинками-ссылками на Figma, а `index.html`, CSS и прочие страницы внешних адресов не содержат
