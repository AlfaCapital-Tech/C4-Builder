## MODIFIED Requirements

### Requirement: Флаги команды создания проекта
Команда `c4builder --new` SHALL принимать имя проекта через флаг `--name <name>`;
переданное значение MUST подставляться вместо интерактивного вопроса об имени.
Создание проекта MUST NOT предлагать VSCode-сниппеты — ни промптом, ни флагом — и
MUST NOT создавать каталог `.vscode` в проекте.

#### Scenario: Флаг имени заменяет промпт
- **WHEN** `c4builder --new --name demo` без `--yes`
- **THEN** вопрос об имени не задаётся, а VSCode-сниппеты не предлагаются

#### Scenario: Интерактивное создание спрашивает только имя
- **WHEN** `c4builder --new` без `--name` и без `--yes`
- **THEN** задаётся единственный вопрос — имя проекта; вопрос о VSCode-сниппетах не задаётся

#### Scenario: VSCode-каталог не создаётся
- **WHEN** проект создан через `c4builder --new` любым способом
- **THEN** каталог `.vscode` и файл сниппетов в проекте отсутствуют
