## Why

Интерфейс страницы `site -w` (кнопки вопросов и замечаний, поле ввода, панель review, тосты) есть
только на английском. Пользователи просят русский: документацию пишут и читают русскоязычные
команды, а сайт без перевода выглядит наполовину чужим.

## What Changes

- Интерфейс страницы `site -w` переведён на два языка: английский и русский. Переведены подписи
  кнопок, подсказки, плейсхолдеры, панель review, состояние агента и тосты страницы.
- Язык выбирается по настройке браузера: первый язык из списка предпочтений браузера, который есть в
  словаре (`ru` или `en`), иначе английский.
- Новый ключ `.c4builder` `uiLanguage: auto | en | ru`, по умолчанию `auto`. Без ключа (старые
  проекты) работает `auto`. Явное значение задаёт язык независимо от браузера. Другое значение —
  понятная ошибка конфигурации.
- Числа в русских подписях склоняются: «1 замечание», «2 замечания», «5 замечаний».
- Без изменений, на английском: вывод CLI, текст пачки для агента (`c4builder feedback`), тексты
  ошибок сервера внутри тостов, заголовок раздела вопросов в файлах (`questionsHeading`).
- Тест `cli-language` разрешает кириллицу в одном файле: словаре интерфейса страницы. Во всём
  остальном `src/` кириллица в литералах по-прежнему запрещена.

## Capabilities

### New Capabilities
- `site-ui-language`: язык интерфейса страницы `site -w`: словари RU/EN, выбор по браузеру и
  по ключу `uiLanguage`, что переводится и что остаётся на английском.

### Modified Capabilities
- `cli-commands`: требование «Язык пользовательского вывода CLI» — исключение для словаря
  интерфейса страницы `site -w`. Вывод CLI остаётся только на английском.

## Impact

- `src/cli/commands/site.comments.ts` — тексты страницы берутся из словаря; новый модуль словаря.
- `src/config/{schema,defaults,options}.ts`, `src/cli/dispatch.ts`, `src/cli/commands/site.ts` — ключ
  `uiLanguage` и его передача в скрипт страницы.
- `test/cli-language.test.mjs` — исключение для словаря и паритет ключей RU/EN;
  `test/site-comments-client.test.mjs`, тесты конфигурации.
- Страницы «05 CLI и конфигурация» и «08 Агенты» (RU/EN), `skills/c4builder/references/config.md`,
  `template/AGENTS.md`, CHANGELOG.
- Зависит от `review-panel-done`: переводятся уже новые подписи панели.
