# dev-toolchain — Biome, lint-джоба CI, гигиена package.json

## Why

Стартовое звено перехода на современный стек (решения explore-сессии 2026-07-05:
Biome 2, далее tsc → dist/ и порт на TS). Прежде чем трогать код, нужна планка
качества, которая держится автоматически: единый линтер/форматтер и CI-джоба,
падающая на нарушениях. Сейчас в репо нет ни линтера, ни формат-контроля, стиль
исторически разнородный, а npm-пакет публикует всё дерево репозитория
(в `package.json` нет `files` — в пакет попадают openspec/, docs/, test/).

## What Changes

- **Biome 2** как единственный линтер и форматтер (devDependency, пин версии):
  - `biome.json`: форматтер настраивается под существующий стиль кода
    (4 пробела, одинарные кавычки, ширина ~110), чтобы дифф форматирования был минимален;
  - линт от `recommended`; правила, требующие рефакторинга, точечно отключаются
    с комментарием — включим в звеньях TS-порта;
  - ignore: `vendor/`, `template/`, `docs/`, `test/golden/`, `node_modules/`
    (вендорное, пользовательский контент fixture и эталоны не форматируем).
- Форматирование всего репо — отдельным коммитом (без ручных правок в нём).
- Тривиальные автофиксы линта отдельным коммитом, каждый — без изменения
  поведения (напр. мёртвый импорт `joi` в build.js:32, `new Buffer.from` →
  `Buffer.from` в utils.js:63). Golden остаётся зелёным.
- npm-скрипты: `lint` (проверка), `lint:fix`, `format` (запись), `check` (biome ci).
- **CI**: отдельная быстрая джоба `lint` в `ci.yml` (biome ci, без Java и матрицы).
- **package.json**:
  - `files`-whitelist: в npm-пакет попадают только код CLI, `template/`, `vendor/`, README;
  - `engines.node >= 20.19` (решение explore-сессии; Docker-образ на node:24 —
    в звене scaffold, где появится build-стадия).

Не входит (следующие звенья): tsconfig/tsc, `src/`-раскладка, ESM, переименования
файлов, апгрейды зависимостей.

## Capabilities

### New Capabilities

- `dev-toolchain`: линт и формат кодовой базы — единый инструмент (Biome),
  конфигурация, npm-скрипты, зона покрытия (что игнорируется и почему),
  требования к составу npm-пакета (`files`) и минимальной версии Node (`engines`).

### Modified Capabilities

- `ci-validation`: workflow дополняется lint-джобой — нарушение линта/формата
  даёт красный статус PR наравне с тестами.

## Impact

- Новые файлы: `biome.json`; правки: `package.json` (devDependency, scripts,
  files, engines), `.github/workflows/ci.yml` (джоба lint).
- Один крупный формат-коммит по всем *.js/*.mjs/*.json репо (кроме ignore-зон).
- Поведение CLI не меняется: golden-тест зелёный до и после каждого коммита звена.
- Потребители пакета: npm-пакет худеет (files), установка на Node <20.19 начнёт
  предупреждать/падать при engine-strict — осознанное решение (Node 20 EOL).
