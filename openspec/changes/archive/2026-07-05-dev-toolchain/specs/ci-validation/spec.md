# ci-validation — delta (dev-toolchain)

## ADDED Requirements

### Requirement: Линт и формат проверяются на CI
Workflow CI SHALL содержать отдельную джобу `lint` (вне node-матрицы, без установки Java), выполняющую проверку линта и формата пинованной версией Biome (`biome ci`). Нарушение линта или формата MUST приводить к красному статусу проверки PR наравне с падением тестов.

#### Scenario: Нарушение формата в PR
- **WHEN** в PR попадает файл, не соответствующий сконфигурированному формату или правилам линта
- **THEN** джоба `lint` завершается с ненулевым кодом и PR получает failed-статус

#### Scenario: Линт не тянет тяжёлое окружение
- **WHEN** выполняется джоба `lint`
- **THEN** среди её шагов нет установки Java и запуска тестов — только checkout, setup-node, установка зависимостей и `biome ci`
