## Why

Агенты (Claude Code, Codex, Cursor) уже пишут C4-модели, но не знают устройства проекта
c4builder, конвенций C4-PlantUML и главного: цикла правка → `c4builder check` → сборка,
который даёт агенту быструю проверку без человека. Единственный скилл сейчас — корпоративный
`c4builder-setup` в отдельном маркетплейсе: он привязан к внутреннему Artifactory и
версионируется отдельно от продукта. Remotion показал рабочую модель: скиллы лежат в
репозитории продукта, ставятся одной командой для любого агента и предлагаются при создании
проекта. Это и есть адаптация инструмента под агентскую разработку, а не только документация.

## What Changes

- **Каталог `skills/` в репозитории** в формате Agent Skills (`SKILL.md` с frontmatter),
  устанавливается командой `npx skills add AlfaCapital-Tech/C4-Builder/skills` в любой
  поддерживаемый агент. В npm-пакет скиллы не входят.
- **Первый набор из двух скиллов** (английский текст, без внутренних хостов):
  - `c4builder` — общий: структура проекта и `.c4builder`, конвенции C4-PlantUML
    (stdlib-инклюды, `.iuml`, кириллица), цикл правка → `check` → `--site -w`, D2,
    плагины `openspec`/`openapi`, `llms.txt`;
  - `c4builder-setup` — установка и диагностика: npm/Docker, каналы `latest`/`rc`, Java
    или managed JRE, функциональный smoke на шаблонном проекте.
- **Шаблон `new` содержит `AGENTS.md`**: как собирать и проверять проект, команда установки
  скиллов. Файл лежит вне `src/` шаблона и в сайт не попадает.
- **CLI понимает позиционные `new` и `config`** (`c4builder new`, `c4builder config`) —
  форма, которой учат README, шаблон и скиллы; сейчас она молча запускает сборку.
  Неизвестный позиционный аргумент даёт ошибку и код 1 вместо сборки.
- **CI проверяет скиллы**: валидный frontmatter (`name` совпадает с именем папки, есть
  `description`) и упомянутые в скиллах команды/флаги CLI существуют.
- Вне скоупа: скилл сверки C4-модели с кодом (обобщение внутренних `arch-review`/
  `arch-actualize`) — следующий change. Перевод корпоративного плагина `c4builder` на
  публичные скиллы (останется тонкая обёртка над Artifactory) — отдельно, в репозитории
  маркетплейса.

## Capabilities

### New Capabilities
- `agent-skills`: состав и формат поставляемых скиллов, способ установки, проверка в CI.
- `cli-commands`: позиционные подкоманды CLI (`check`, `jre`, `site`, `new`, `config`) и
  ошибка на неизвестную.

### Modified Capabilities
- `project-template`: шаблон содержит `AGENTS.md` с инструкциями для агента.

## Impact

- Новые `skills/c4builder/SKILL.md`, `skills/c4builder-setup/SKILL.md` (+ references при
  необходимости).
- `src/cli/dispatch.ts` — позиционные `new`/`config`, ошибка на неизвестную подкоманду.
- `template/AGENTS.md`; golden-эталоны не меняются (файл вне `src/`).
- `.github/workflows/ci.yml` или vitest — проверка скиллов.
- Документация: страница «Работа с агентами» (сайт из `docs-site`; до его реализации —
  README) и changelog.
- Связь с `llms-txt`: общий скилл упоминает `llms.txt`. Если `llms-txt` ещё не
  реализован, упоминание добавляется последней задачей.
- Новых npm-зависимостей нет.
