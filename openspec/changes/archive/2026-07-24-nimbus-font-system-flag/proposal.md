# Смена вендорного шрифта на Nimbus Sans + опция системных шрифтов

## Why

Обратная связь от пользователей: после пина вендорного Liberation Sans (клон Arial)
внешний вид диаграмм изменился — раньше рендер брал системный шрифт (на Mac —
Helvetica). Nimbus Sans (URW base35) — метрический клон Helvetica с кириллицей —
возвращает привычный вид, оставаясь детерминированным. Тем, кому нужен буквально
прежний вид «как на моей машине», нужен явный путь отката на системные шрифты.

## What Changes

- Вендорный шрифт заменяется: Liberation Sans → **Nimbus Sans** (4 начертания,
  OTF, релиз urw-base35 20200910, AGPL-3.0 + шрифтовое исключение) в
  `vendor/fonts/`; `DEFAULT_FONT_NAME` обновляется.
- Новая опция **`useSystemFonts`** (bool, default `false`) в `.c4builder` +
  CLI-флаг **`--system-fonts`** (разовое переопределение, приоритет над конфигом):
  при включении пин шрифта снимается в обоих движках — JVM/PlantUML рендерит
  системным шрифтом (как до ветки phoenix), resvg растрирует с
  `loadSystemFonts: true`.
- Кеш рендера учитывает режим шрифта (имя вендорного шрифта или `system`) —
  переключение режима не отдаёт устаревшие картинки из кеша.
- Golden-эталоны пересобираются под Nimbus Sans; golden-контур всегда работает на
  вендорном шрифте (`useSystemFonts` в нём не участвует — системные шрифты
  недетерминированы по определению).
- **BREAKING (визуально):** вид текста диаграмм по умолчанию меняется
  (Arial-метрики → Helvetica-метрики). Поведение сборки и API не меняются.

## Capabilities

### New Capabilities

_нет_

### Modified Capabilities

- `diagram-rendering`: требование «Детерминированные метрики текста через вендорный
  шрифт» — вендорным шрифтом становится Nimbus Sans; добавляется требование
  режима системных шрифтов (опция снимает пин в JVM и resvg, кеш различает режимы).
  Ключ `useSystemFonts` в схеме `.c4builder` — реализация существующего требования
  `config-validation` («схема — единый источник»), его дельта не нужна.

## Impact

- `vendor/fonts/*` + `vendor/fonts/README.md` — замена файлов, происхождение/лицензия.
- `src/core/render/fonts.ts` — имя шрифта; `src/core/render/diagrams.ts` — условная
  передача JVM-флагов шрифта и ключ кеша; `src/core/render/pngraster.ts` — условный
  `loadSystemFonts`.
- `src/config/schema.ts`, `defaults.ts`, `options.ts` — ключ `useSystemFonts`;
  `src/cli/dispatch.ts` — флаг `--system-fonts`.
- `test/golden/*` — пересборка эталонов; golden остаётся на linux-контуре CI
  (матрица ОС не добавляется), CFF на windows/macos не проверяется — план Б при
  жалобе: конвертация OTF→TTF на этапе вендоринга.
- Docker-образ подхватывает новые файлы из `vendor/fonts/` автоматически.
- Потребитель `arch`: конфиг не меняется, сборка совместима; меняется только
  внешний вид текста.
