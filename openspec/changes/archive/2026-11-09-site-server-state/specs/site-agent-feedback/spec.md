## MODIFIED Requirements

### Requirement: Команда получения замечаний
`c4builder feedback --wait --as <name>` SHALL подключаться к dev-серверу `site -w` текущего проекта
(порт — из `-p`, иначе из действительного файла состояния сервера, иначе из ключа `webPort` в
`.c4builder`; c4builder другого проекта на этом порту MUST NOT считаться сервером проекта — код 1 и
сообщение на английском), ждать следующую пачку для имени `<name>` без
ограничения по времени, печатать её в stdout и завершаться с кодом 0. `c4builder feedback --as <name>`
без `--wait` SHALL печатать первую пачку для этого имени, если она есть, иначе ничего, и сразу
завершаться с кодом 0. Имя MUST быть от 1 до 64 символов из латинских букв, цифр, `.`, `_` и `-`.
Без `--as` или с недопустимым именем команда MUST сразу завершаться с кодом 2 (а не 1, как при
недоступном сервере), не обращаясь к серверу, и сообщением на английском, что `--as <name>`
обязателен, с примером команды. Запрос пачек без
допустимого имени сервер MUST отклонять и MUST NOT выдавать по нему пачки. Если сервер недоступен или
агентский режим выключен, команда MUST завершаться с ненулевым кодом и сообщением на английском, где
указан адрес сервера. Команда MUST NOT создавать `.c4builder` и иные файлы в каталоге и MUST NOT
запускать сборку.

#### Scenario: Сервер не запущен
- **WHEN** в каталоге проекта без запущенного `site -w` выполняется `c4builder feedback --wait --as foo`
- **THEN** команда сразу завершается с ненулевым кодом и сообщением, что на `http://localhost:<port>` нет `c4builder site -w`

#### Scenario: Проверка без ожидания
- **WHEN** ящик `foo` пуст и выполняется `c4builder feedback --as foo`
- **THEN** команда ничего не печатает в stdout и завершается с кодом 0

#### Scenario: Запуск без имени
- **WHEN** агент со старой инструкцией выполняет `c4builder feedback --wait`, а пачка ждёт в очереди
- **THEN** команда сразу завершается с кодом 2 и сообщением, что нужен `--as <name>`, с примером `c4builder feedback --wait --as <name>`; пачка остаётся в очереди

#### Scenario: Сервер на другом порту
- **WHEN** сервер проекта запущен с `-p 3001` при `webPort` 3000, и выполняется `c4builder feedback --wait --as foo` без `-p`
- **THEN** команда подключается к `http://localhost:3001` по файлу состояния и ждёт пачку для `foo`
