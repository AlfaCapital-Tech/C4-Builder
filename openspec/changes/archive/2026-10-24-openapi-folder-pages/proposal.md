## Why

Плагин `openapi` строит страницу на каждую спеку и называет её по родительской папке. В репозиториях
контрактов API сервиса часто специально разбит на несколько файлов, чтобы его было удобнее читать
(`billing/openapi.yaml`, `billing/openapi-admin.yaml`, `billing/payouts.yaml`). Ещё бывают версии во
вложенных папках (`billing/v2/openapi.yaml`, `ledger/v2/openapi.yaml`). Такие спеки дают одинаковое
имя страницы, и сборка падает (`two specs give the same page name`). Обойти это можно только
сужением `glob` до одного `openapi.yaml` на папку, а остальные спеки на сайт не попадают. Широкий
`glob` (`**/*.yaml`) тоже не помогает: он подхватывает конфиги, общие файлы схем и AsyncAPI.

## What Changes

- По-прежнему **одна страница на спеку**, но страницы раскладываются по папкам источника, и имена
  не сталкиваются:
  - если в папке одна спека, её страница — сама папка, как сейчас (`billing`);
  - если спек несколько, папка — страница-оглавление со ссылками, а у каждой спеки вложенная
    страница с именем файла без расширения (`billing/openapi`, `billing/openapi-admin`,
    `billing/payouts`);
  - путь страницы папки задаёт новая опция `layout`: `flat` (по умолчанию) — имя папки, как
    сейчас; `tree` — путь папки относительно источника, тогда версии во вложенных папках дают
    вложенные страницы (`billing/v2`, `ledger/v2`).
- Ошибки «same page name» для спек одной папки больше нет. Существующие сайты адресов не меняют:
  при `flat` страница папки с одной спекой остаётся прежней, а одноимённые папки в разных местах
  источника — по-прежнему ошибка, теперь с подсказкой включить `tree`.
- Спекой считается только файл, отобранный `glob`, у которого есть ключ верхнего уровня `openapi` или
  `swagger`. Остальные файлы страниц не получают (с предупреждением в логе), но копируются в
  `<mount>/_specs/` для `$ref`, как сейчас. С таким отбором `glob: "*/*.{yaml,yml,json}"` берёт все
  спеки папки. Значение `glob` по умолчанию не меняется.
- Сводка раздела перечисляет все страницы спек с полным путём.

### Modified Capabilities

## Impact

- Код: `src/plugins/openapi/index.ts`.
- Тесты: `test/plugin-openapi.test.mjs` — тест коллизии имён заменяется на тесты папки с несколькими
  спеками, вложенных папок и отбора по содержимому.
- Документация: «06 Плагины» (RU/EN), `skills/c4builder/references/plugins.md`, CHANGELOG.
- Пользователи: адреса существующих страниц сохраняются (`layout: "flat"` по умолчанию). Папка, в
  которой к `openapi.yaml` добавилась вторая спека, меняет свою страницу на оглавление. Файл
  `openapi.yaml` без ключа `openapi`/`swagger` (фрагмент схем) больше не получает страницу — об
  этом предупреждает лог.
