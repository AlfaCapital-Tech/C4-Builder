# Proposal

## Why

Макет экрана нужен рядом с текстом, который его описывает: в design.md change'а, на странице
сервиса. Плагин `figma` умеет только отдельный раздел фреймов из опций, поэтому на страницах
остаются голые ссылки на Figma, а читатель уходит из документации, чтобы посмотреть макет.

## What Changes

- При подключённом плагине `figma` картинка-ссылка на Figma в markdown любой страницы
  (`![подпись](https://www.figma.com/design/…?node-id=…)`), стоящая одна на строке, превращается в
  эмбед на месте: ссылка «Open in Figma: подпись» и iframe `embed.figma.com` (те же правила
  нормализации, `embedHost`, `height`, что у страниц фреймов). Внутри текста — обычная ссылка;
  в блоках кода — без изменений; неразбираемая ссылка — без изменений и предупреждение.
- Обрабатываются страницы проекта и страницы плагинов, объявленных в `plugins` раньше `figma`
  (например, артефакты OpenSpec).
- `frames` становится необязательным: без фреймов раздела нет, плагин работает только эмбедами.
- Строка лога называет число страниц фреймов и эмбедов в страницах.
