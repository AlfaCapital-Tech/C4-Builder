# Spec Delta

## ADDED Requirements

### Requirement: Чексуммы кэша сохраняются по мере рендера
Чексумма успешно отрендеренной диаграммы SHALL попадать в `.c4builder.cache` по мере рендера, а
не только по окончании фазы. Прерванная сборка (сигнал, ошибка другой диаграммы) MUST оставлять в
кэше готовые диаграммы, и следующая сборка MUST брать их из кэша, перерисовывая только остальные.

#### Scenario: Ctrl+C посреди холодной сборки
- **WHEN** сборка со 179 диаграммами прервана после 100 готовых
- **THEN** следующая сборка рендерит 79 диаграмм, 100 берёт из кэша

#### Scenario: Повторная сборка без прерываний
- **WHEN** сборка выполнена дважды без изменений
- **THEN** выходное дерево второго прогона идентично первому, как и раньше

### Requirement: Параллелизм рендера PlantUML
Диаграммы PlantUML SHALL рендериться параллельно: по умолчанию `min(4, CPU − 1)` процессов, не
менее одного; переменная окружения `C4BUILDER_RENDER_CONCURRENCY` (целое ≥ 1) MUST
переопределять это число. Результат рендера MUST NOT зависеть от степени параллелизма.

#### Scenario: Больше воркеров на мощной машине
- **WHEN** `C4BUILDER_RENDER_CONCURRENCY=8` на машине с 16 ядрами
- **THEN** одновременно выполняются до 8 рендеров, выход побайтно совпадает со сборкой при значении по умолчанию
