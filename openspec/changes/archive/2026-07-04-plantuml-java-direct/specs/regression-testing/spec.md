# regression-testing

## ADDED Requirements

### Requirement: Golden-эталон воспроизводим независимо от машины
Golden-эталон SHALL быть детерминированным и не зависеть от версии внешнего graphviz —
за счёт Java-движка раскладки (Smetana) и вендорного шрифта. Регенерация эталона на
разных машинах с одинаковой мажорной версией JDK MUST давать идентичное дерево
выходов; необходимость калибровать эталон исключительно по CI-раннеру устраняется.

#### Scenario: Регенерация на разных машинах
- **WHEN** эталон регенерируется на двух машинах с одинаковой мажорной версией JDK
  и одним вендорным JAR/шрифтом
- **THEN** нормализованное дерево выходов идентично

#### Scenario: Локальный прогон совпадает с CI
- **WHEN** разработчик запускает `npm test` локально при совпадающей мажорной версии JDK
- **THEN** golden-тест проходит без расхождений с эталоном, снятым на CI
