# Spec Delta

## ADDED Requirements

### Requirement: Шаблон демонстрирует wireflow
Шаблон MUST содержать раздел с файлом `.wireflow.json` текущего формата: группа из нескольких
карточек экранов с шаблонами, заметка и рёбра с подписями, подписи кириллические. Страница
раздела MUST пояснять, что файл — экспорт редактора Wireflow, который рендерится при сборке.

#### Scenario: Wireflow-пример в новом проекте
- **WHEN** собирается новый проект из шаблона
- **THEN** wireflow-диаграмма раздела отрендерена картинкой, а `c4builder check` для `.wireflow.json`-файла завершается с кодом 0
