# dev-toolchain — delta (zod-and-deps-upgrade)

## ADDED Requirements

### Requirement: Рантайм-зависимости без известных уязвимостей

Рантайм-зависимости SHALL поддерживаться без известных уязвимостей уровня ≥ high.
CI MUST проверять это аудитом зависимостей и давать красный статус при регрессе,
чтобы новая уязвимость не проходила молча.

#### Scenario: Аудит зависимостей на CI
- **WHEN** выполняется CI
- **THEN** отдельная проверка аудита зависимостей проходит только при отсутствии известных уязвимостей уровня ≥ high

#### Scenario: Новая уязвимость ловится
- **WHEN** изменение зависимостей вносит известную уязвимость уровня ≥ high
- **THEN** проверка аудита падает с красным статусом, не пропуская регресс молча
