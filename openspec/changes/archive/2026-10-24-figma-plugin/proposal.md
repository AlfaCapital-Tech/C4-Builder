# Proposal

## Why

Макеты интерфейсов живут в Figma, а архитектурный сайт c4builder о них ничего не знает: читателю
приходится искать ссылки на фреймы вручную, и они быстро расходятся с документацией. Нужен
раздел сайта с фреймами Figma — по аналогии с плагином `openapi`, который публикует контракты
рядом с C4-моделью.

## What Changes

- Новый встроенный плагин `figma`: в опциях — список фреймов (имя, ссылка Figma, описание);
  на выходе — раздел сайта (`mount`, по умолчанию `Figma`) со страницей-сводкой и страницей на
  каждый фрейм.
- Страница фрейма — живой iframe-эмбед Figma (Embed Kit 2.0, `embed.figma.com`, параметр
  `embed-host`) и всегда видимая ссылка «Open in Figma»: без сети или без доступа к файлу у
  читателя остаётся рабочая ссылка.
- Ссылки Figma валидируются и нормализуются при загрузке плагина (`design`/`file`/`proto`/
  `board`/`slides`/`deck`, `node-id` сохраняется); неверная ссылка или дубль имени — ошибка
  до старта сборки.
- Плагин явно выпадает из офлайн-гарантии: он не включён по умолчанию, а при подключении
  страницы фреймов грузят `embed.figma.com` в браузере читателя — сборка пишет об этом строку
  в лог. Сама сборка в сеть не ходит.
- Документация: страница «Плагины» (RU/EN), skills, CHANGELOG.

## Capabilities

### New Capabilities
- `figma-plugin`: публикация фреймов Figma разделом docsify-сайта — опции, валидация ссылок,
  страницы-эмбеды, поведение без сети.

### Modified Capabilities
- `offline-site`: требование «Сайт по умолчанию не обращается к внешним доменам» получает явное
  исключение для страниц плагина, назначение которого — эмбед внешнего сервиса (`figma`),
  подключённого пользователем.

## Impact

- Код: `src/plugins/figma/index.ts` (новый), `src/plugins/index.ts` (реестр).
- Тесты: `test/plugin-figma.test.mjs`; `offline-site` не меняется (шаблон плагин не подключает).
- Зависимостей нет: ни вендорных ассетов, ни `executeScript` — iframe обычный HTML в markdown.
- Документация: `docs/{ru,en}/src` (страница плагинов, обзор, `context.puml`),
  `skills/c4builder/SKILL.md`, `skills/c4builder/references/plugins.md`, `CHANGELOG.md`.
