# Spec Delta

## ADDED Requirements

### Requirement: Golden-тест покрывает mermaid-рендер
Golden-fixture SHALL включать:
- файл `.mmd` с flowchart (с `subgraph` и подписью ребра);
- блок ```` ```mermaid ```` в md-странице с sequence-диаграммой (с заметкой и пунктирным ответом).

Все подписи — кириллические. Golden-тест MUST сравнивать SVG-выход (вариант `default`) и PNG-выход (вариант `embed-png`) этих диаграмм с эталонами наравне с остальными движками. Детерминизм обеспечивается вендорным шрифтом для метрик текста и точным пином версии движка.

#### Scenario: Mermaid в fixture совпадает с эталоном
- **WHEN** golden-тест собирает fixture, содержащий `.mmd` и блок ```` ```mermaid ````
- **THEN** их SVG (после нормализации) совпадают с закоммиченными эталонами

#### Scenario: Повторный прогон mermaid идентичен
- **WHEN** сборка fixture с mermaid выполняется дважды
- **THEN** SVG-выходы mermaid-диаграмм байт-в-байт совпадают между прогонами

#### Scenario: Обновление движка ловится тестом
- **WHEN** версия mermaid-движка меняется и меняет раскладку
- **THEN** golden-тест падает до явного переснятия эталона
