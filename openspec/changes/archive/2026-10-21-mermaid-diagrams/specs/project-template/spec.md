# Spec Delta

## MODIFIED Requirements

### Requirement: Демо-проект собирается офлайн
Проект, созданный `c4builder new`, SHALL собираться без доступа в интернет: рендер всех диаграмм шаблона (PlantUML, D2, BPMN, mermaid) MUST выполняться локальными движками без сетевых обращений.

#### Scenario: Сборка нового проекта без сети
- **WHEN** проект создан из шаблона и `c4builder` запущен в окружении без доступа в интернет
- **THEN** сборка завершается успешно и все диаграммы шаблона отрендерены

## ADDED Requirements

### Requirement: Шаблон демонстрирует mermaid
Шаблон MUST содержать раздел с mermaid-диаграммами в обоих видах источника. Первый — файл `.mmd` с flowchart. Второй — блок ```` ```mermaid ```` в md-странице с sequence-диаграммой. Подписи кириллические. Страница раздела MUST пояснять:
- блок рендерится при сборке в картинку, как ```` ```plantuml ````;
- `mindmap` и `architecture` не поддерживаются.

#### Scenario: Mermaid-пример в новом проекте
- **WHEN** собирается новый проект из шаблона
- **THEN** обе mermaid-диаграммы раздела отрендерены картинками, а `c4builder check` для `.mmd`-файла завершается с кодом 0
