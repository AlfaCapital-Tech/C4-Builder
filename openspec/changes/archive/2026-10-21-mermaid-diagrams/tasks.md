## 2. Рендер: геометрия, конфиг, детерминизм

- [x] 2.1 Полифил `getBBox`/`getComputedTextLength` через resvg (design §3):
  - поддерево без собственного `transform`;
  - обёртка наследует `fontFamily`/`fontSize` из конфигурации;
  - `loadSystemFonts: false`, округление результатов.

  Проверка: юнит-тест — у flowchart с кириллическими подписями подписи помещаются в фигуры (ширина `<text>` по resvg ≤ ширины фигуры), viewBox ненулевой.
- [x] 2.2 Фиксированная конфигурация mermaid и `secure`-ключи (design §4): `look: classic`, `htmlLabels: false`, `gantt.useWidth`, вендорный шрифт. Проверка — юнит-тесты:
  - flowchart (subgraph), sequence (note, пунктирный ответ), state, ER, class, gantt, pie рендерятся;
  - у gantt ненулевая ширина;
  - в SVG нет `foreignObject`, `filter`, `@import` и `http`;
  - `%%{init: {"look":"neo"}}%%` не включает neo.
- [x] 2.3 Подогнать полифил под шероховатости спайка (design §3): центрирование подписей state, текст в цилиндре flowchart, подпись пунктирной стрелки sequence. Причина всех трёх — ink-bbox текста от resvg вместо браузерного (advance-ширина, em-box) и CSS mermaid, который jsdom не применяет к SVG; полифил эмулирует раскладку текста и мини-каскад CSS. Подписи state выровнены влево и в Chrome — это поведение mermaid при `htmlLabels: false`, а не полифила. Проверка:
  - юнит-тест сверяет размеры всех обязательных типов с эталоном headless Chrome (допуск 1 px);
  - сравнение бок о бок с эталоном браузера: те же источники рендерятся настоящим mermaid из локального `node_modules` в headless Chrome (chrome-devtools, без CDN), расхождения в раскладке и размерах фигур разобраны;
  - остаются только шрифтовые отличия, они перечислены на странице «Диаграммы» (6.3).
- [x] 2.4 Детерминизм (design §5):
  - seed `window.Math.random` на время рендера, с восстановлением после;
  - id рендера от хэша источника;
  - постобработка id, `url(#…)` и `href="#…"` в документ-локальные;
  - рендеры строго последовательные.

  Проверка — юнит-тест:
  - sequence, ER и class, отрендеренные дважды в одном процессе, побайтно равны;
  - SVG диаграммы не зависит от того, рендерилась ли перед ней другая;
  - `Math.random` окна после рендера — исходный.
- [x] 2.5 PNG через штатную растеризацию. Проверка: тест — PNG flowchart и sequence содержат непустые пиксели в области узлов и участников, т.е. фигуры не пропали из-за фильтров.
