## Context

`c4builder --new` (`cmdNewProject`) после ввода имени спрашивает «Include the VSCode
autocomplete?» и при согласии копирует `vendor/C4-PlantUML/C4.code-snippets` в
`<project>/.vscode/C4.code-snippets`. `new-noninteractive` добавил флаги
`--vscode`/`--no-vscode` и `vscodeExplicit` (различить явный флаг от дефолта), чтобы
пропускать этот промпт. Каталог `vendor/C4-PlantUML/` содержит ровно один файл — эти
сниппеты; больше его никто не читает.

## Goals / Non-Goals

**Goals:**
- Убрать фичу VSCode-сниппетов целиком: промпт, флаги, copy-шаг, вендорный ассет.
- Интерактивный `--new` — только вопрос имени.
- Не задеть `--name`, `-y/--yes`, `defaultConfig`, headless-режим.

**Non-Goals:**
- Убирать упоминание стороннего `vscode-plantuml` из README (это про вьюер, не про фичу).
- Трогать шаблон, golden/CI, пути сборки.

## Decisions

### Убираем фичу целиком, не прячем за дефолтом
Единственный потребитель ассета, ценность не подтверждена — удаляем промпт, флаги и
copy-шаг, а не оставляем «выключенным по умолчанию». Меньше поверхности.
*Альтернатива* — оставить флаг `--vscode` выключенным по умолчанию: отвергнута,
мёртвый код и ассет ради неиспользуемой опции.

### Вендорный каталог `C4-PlantUML/` удаляем целиком
В нём только `C4.code-snippets`, и его читал лишь copy-шаг. Stdlib-инклюды `<C4/...>`
в диаграммах резолвит сам PlantUML-jar (проверено на golden), не этот каталог —
удаление безопасно.
*Альтернатива* — оставить файл «на всякий»: отвергнута, мёртвый груз в пакете.

### Интерактивный `--new` — только имя
После снятия VSCode-вопроса в интерактиве остаётся единственный промпт — имя проекта
(с прежней валидацией и ре-промптом). С `--name` вопросов нет. `--yes`/headless
не меняются.

### README-упоминание vscode-plantuml оставляем
Строка про плагин `vscode-plantuml` — совет по стороннему вьюеру `.puml`, не про
scaffold-фичу c4builder. Вне объёма.

## Risks / Trade-offs

- **Пользователи, полагавшиеся на авто-сниппеты** → сниппеты доступны из расширения
  C4-PlantUML в редакторе; c4builder перестаёт их навязывать. Отметить в change-логе.
- **Ветка `jre-resolver` держала свою копию `cli.new.js`** → консолидирована в
  phoenix, отдельного расхождения больше нет.
