# Proposal

## Why

Асинхронные контракты сервисов (Kafka-топики, сообщения) лежат в тех же репозиториях контрактов
рядом с OpenAPI — в формате AsyncAPI (`asyncapi.yaml`). Плагин `openapi` сейчас считает такой файл
«не спекой»: страницы нет, в логе предупреждение. На сайте видна только синхронная половина API
сервиса.

## What Changes

- Файл, отобранный `glob`, с ключом верхнего уровня `asyncapi` — тоже спека: получает свою страницу
  по тем же правилам раскладки (одна спека в папке — страница папки, несколько — оглавление и
  страницы по имени файла), попадает в сводку и оглавление папки с `info.title`.
- Страница AsyncAPI-спеки отображает её официальным компонентом AsyncAPI
  (`@asyncapi/react-component`, standalone-бандл, Apache-2.0), вендоренным в пакет: без CDN и без
  обращения к внешним адресам.
- Бандл (~2,9 МБ) и его стиль копируются в выход и загружаются браузером только на страницах
  AsyncAPI-спек — сайты без AsyncAPI не меняются и не тяжелеют.
- Предупреждение о пропуске теперь — для файлов без ключа `openapi`/`swagger`/`asyncapi`.
