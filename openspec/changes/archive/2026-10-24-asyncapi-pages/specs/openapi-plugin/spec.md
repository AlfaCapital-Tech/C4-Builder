# Spec Delta

## MODIFIED Requirements

### Requirement: Раздел API из набора спек

Встроенный плагин `openapi` SHALL строить раздел сайта под точкой монтирования (`mount`, по
умолчанию `API`) из файлов источника (`dir` либо `archive` — ровно один), отобранных по
`glob` (по умолчанию `**/openapi.{yaml,yml,json}`). Спекой MUST считаться только отобранный файл с
ключом верхнего уровня `openapi` или `swagger` (OpenAPI) либо `asyncapi` (AsyncAPI); отобранный файл
без этих ключей MUST давать предупреждение в логе с его путём. Каждая спека MUST получать свою страницу. Путь страницы папки задаёт опция
`layout`: `flat` (по умолчанию) — имя родительской папки спеки, как раньше; `tree` — путь папки
относительно источника. Внутри папки:
- одна спека — её страница по пути папки;
- несколько спек — по пути папки страница-оглавление со ссылками на страницы спек, а у
  каждой спеки страница с путём папки и именем файла без расширения;
- спека в корне источника — страница с именем файла без расширения.

Совпадение пути двух страниц (спеки одной папки с одним именем без расширения, спека и папка с тем
же именем, при `flat` — одноимённые папки в разных местах источника) MUST прерывать сборку с
указанием пути страницы и обоих файлов; для одноимённых папок сообщение MUST подсказывать
`layout: "tree"`. Страница-сводка раздела
MUST перечислять все страницы спек по алфавиту пути со ссылками и полным путём. Отсутствие спек
после отбора MUST прерывать сборку с указанием источника и шаблона.

#### Scenario: Спеки репозитория контрактов
- **WHEN** источник — архив репозитория с `finch/openapi.yaml`, `selling-agent/openapi.yaml`, `common/openapi.yaml`
- **THEN** раздел содержит страницы `finch`, `selling-agent`, `common` и сводку со ссылками на них

#### Scenario: Несколько спек в одной папке
- **WHEN** `glob` — `**/*.yaml`, а в источнике `billing/openapi.yaml`, `billing/openapi-admin.yaml` и `billing/payouts.yaml`
- **THEN** раздел содержит оглавление `billing` со ссылками на три страницы `billing/openapi`, `billing/openapi-admin`, `billing/payouts`, на каждой одна спека, и сборка не прерывается

#### Scenario: Глубокая раскладка без опции
- **WHEN** `layout` не задан, а в источнике `services/team/finch/openapi.yaml`
- **THEN** страница спеки — `finch`, как до появления опции

#### Scenario: Версия во вложенной папке
- **WHEN** `layout: "tree"`, а в источнике `billing/openapi.yaml`, `billing/v2/openapi.yaml` и `ledger/v2/openapi.yaml`
- **THEN** раздел содержит страницы `billing`, `billing/v2` и `ledger/v2`, а сводка перечисляет все три с полным путём

#### Scenario: Одноимённые папки в плоской раскладке
- **WHEN** `layout` не задан, а в источнике `billing/v2/openapi.yaml` и `ledger/v2/openapi.yaml`
- **THEN** сборка прерывается с сообщением, называющим путь страницы `v2`, оба файла и опцию `layout: "tree"`

#### Scenario: Файлы без ключа openapi не становятся спеками
- **WHEN** `glob` — `**/*.{yaml,json}`, а в источнике кроме спек есть `common/schemas.yaml` без ключа `openapi` и `merge-config.json`
- **THEN** эти файлы не дают страниц и не перечислены в сводке, но скопированы в каталог спек сайта; в логе — предупреждение с путём каждого

#### Scenario: Ни одна спека не найдена
- **WHEN** `glob` не совпадает ни с одним файлом источника или ни один совпавший файл не содержит ключа `openapi`/`swagger`/`asyncapi`
- **THEN** сборка прерывается с сообщением, содержащим источник и шаблон

#### Scenario: Совпадение путей страниц
- **WHEN** в источнике `finch.yaml` и `finch/openapi.yaml` либо `billing/openapi.yaml` и `billing/openapi.json`
- **THEN** сборка прерывается с сообщением, называющим оба файла и путь страницы

#### Scenario: Ошибка конфигурации источника
- **WHEN** заданы одновременно `dir` и `archive` либо ни один из них
- **THEN** сборка не стартует, ошибка называет плагин и опции

#### Scenario: AsyncAPI рядом с OpenAPI
- **WHEN** в папке `events` лежат `openapi.yaml` и `asyncapi.yaml` с ключом `asyncapi: 2.6.0`
- **THEN** `events` — оглавление со ссылками на страницы `events/openapi` и `events/asyncapi` с их `info.title`, обе спеки — в сводке раздела


## ADDED Requirements

### Requirement: Страница AsyncAPI-спеки — офлайн
Страница AsyncAPI-спеки SHALL отображать её компонентом AsyncAPI, вендоренным в пакет. Скрипт и
стиль компонента MUST копироваться в выходной каталог только при наличии AsyncAPI-спек и загружаться
браузером только на страницах таких спек. Спека MUST загружаться относительной ссылкой из каталога
спек сайта; страница MUST NOT ссылаться на внешние CDN и обращаться к внешним адресам.

#### Scenario: Открытие страницы без сети
- **WHEN** собранный сайт открыт в браузере без доступа к интернету
- **THEN** страница AsyncAPI-спеки отрисовывает каналы, операции и сообщения спеки

#### Scenario: Сайт без AsyncAPI
- **WHEN** среди отобранных файлов нет AsyncAPI-спек
- **THEN** в выходном каталоге нет файлов компонента AsyncAPI, `index.html` их не подключает

#### Scenario: Страницы OpenAPI не грузят компонент
- **WHEN** на сайте есть и OpenAPI-, и AsyncAPI-спеки
- **THEN** `index.html` не подключает компонент AsyncAPI; его скрипт запрашивается только при открытии страницы AsyncAPI-спеки
