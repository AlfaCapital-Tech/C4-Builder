## ADDED Requirements

### Requirement: Проект компилируется перед тестами

CI workflow MUST компилировать проект (`tsc`) до прогона тестов на каждой ноде матрицы, так как тесты исполняют собранный CLI из `dist/`. Ошибка компиляции MUST приводить к красному статусу проверки PR наравне с падением тестов и линта.

#### Scenario: Сборка перед тестами
- **WHEN** выполняется job тестовой матрицы (Node 22/24)
- **THEN** среди шагов присутствует сборка (`npm run build` / `tsc`) перед запуском тестов, и тесты исполняют CLI из `dist/`

#### Scenario: Ошибка компиляции в PR
- **WHEN** в PR попадает код, не компилируемый `tsc`
- **THEN** job завершается с ненулевым кодом и PR получает failed-статус проверки
