## MODIFIED Requirements

### Requirement: Единый линтер и форматтер
Репозиторий SHALL использовать Biome (пин точной версии в devDependencies) как единственный линтер и форматтер JS/TS/JSON-кода. Конфигурация `biome.json` MUST соответствовать существующему стилю кода (отступ 4 пробела, одинарные кавычки, точки с запятой, ширина строки ~110) и MUST покрывать исходники под `src/**/*.ts`, а линт MUST базироваться на наборе `recommended`; отключение правила или локальный `biome-ignore` MUST сопровождаться комментарием-причиной.

#### Scenario: Локальная проверка
- **WHEN** разработчик запускает `npm run lint` (или `npm run check`)
- **THEN** Biome проверяет линт и формат всех файлов вне ignore-зон (включая `src/**/*.ts`) и завершается ненулевым кодом при нарушениях

#### Scenario: Автоформатирование
- **WHEN** разработчик запускает `npm run format`
- **THEN** Biome приводит файлы к сконфигурированному стилю на месте

#### Scenario: Воспроизводимость версии
- **WHEN** линт/формат запускаются локально и в CI
- **THEN** используется одна и та же пинованная версия Biome и результат идентичен

### Requirement: Состав npm-пакета ограничен whitelist'ом
`package.json` MUST содержать `files`-whitelist, включающий только собранный код CLI (`dist/`), `template/`, `vendor/`, README и лицензию. Служебные директории и исходники (openspec/, docs/, test/, `src/`, CI-конфиги, Dockerfile, tsconfig) MUST NOT попадать в публикуемый пакет. Опубликованный пакет MUST оставаться работоспособным: `c4builder --help` и `c4builder new` с шаблоном и вендорными ресурсами работают из установленного пакета.

#### Scenario: Проверка состава пакета
- **WHEN** выполняется `npm pack --dry-run`
- **THEN** в списке файлов пакета присутствуют `dist/`, `template/`, `vendor/`, README и отсутствуют openspec/, docs/, test/, `src/`, Dockerfile

#### Scenario: Smoke-проверка установленного пакета
- **WHEN** пакет из tarball устанавливается в чистую директорию и запускается `c4builder --help` и неинтерактивный `c4builder --new --name demo -y`
- **THEN** команды завершаются успешно, проект создаётся из шаблона
