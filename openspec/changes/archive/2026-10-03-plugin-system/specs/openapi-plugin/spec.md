## Purpose

Публикация набора OpenAPI-контрактов на docsify-сайте: страница swagger-ui на каждую спеку из
локальной папки или архива репозитория контрактов, полностью офлайн — без внешних CDN и без
запросов из браузера читателя за пределы сайта.

## ADDED Requirements

### Requirement: Раздел API из набора спек

Встроенный плагин `openapi` SHALL строить раздел сайта под точкой монтирования (`mount`, по
умолчанию `API`) из файлов источника (`dir` либо `archive` — ровно один), отобранных по
`glob` (по умолчанию `**/openapi.{yaml,yml,json}`). На каждую найденную спеку MUST быть
страница с именем родительской папки спеки (для файла в корне источника — имя файла без
расширения); страница-сводка раздела MUST перечислять спеки со ссылками по алфавиту. Пустое
совпадение `glob` MUST прерывать сборку с указанием источника и шаблона.

#### Scenario: Спеки репозитория контрактов
- **WHEN** источник — архив репозитория с `finch/openapi.yaml`, `selling-agent/openapi.yaml`, `common/openapi.yaml`
- **THEN** раздел содержит страницы `finch`, `selling-agent`, `common` и сводку со ссылками на них

#### Scenario: Ни одна спека не найдена
- **WHEN** `glob` не совпадает ни с одним файлом источника
- **THEN** сборка прерывается с сообщением, содержащим источник и шаблон

#### Scenario: Ошибка конфигурации источника
- **WHEN** заданы одновременно `dir` и `archive` либо ни один из них
- **THEN** сборка не стартует, ошибка называет плагин и опции

### Requirement: Страница спеки — офлайн swagger-ui

Страница спеки SHALL отображать её через swagger-ui, подключённый из ассетов сайта (скрипт и
стиль вендорены в пакет и копируются в выходной каталог). Файл спеки MUST копироваться в
выходной каталог, сохраняя относительный путь внутри источника, и загружаться swagger-ui
относительной ссылкой — так относительные `$ref` между спеками продолжают разрешаться. Страница
MUST NOT ссылаться на внешние CDN и MUST NOT требовать доступа к исходному репозиторию у
читателя. Плагин SHALL требовать выполнения скриптов на страницах (`executeScript`).

#### Scenario: Открытие страницы без сети
- **WHEN** собранный сайт открыт в браузере без доступа к интернету и к GitLab
- **THEN** страница спеки отрисовывает swagger-ui с содержимым спеки

#### Scenario: Относительные $ref
- **WHEN** `finch/openapi.yaml` ссылается на `../common/openapi.yaml#/components/schemas/Error`
- **THEN** swagger-ui разрешает ссылку по скопированному рядом файлу `common/openapi.yaml`

#### Scenario: executeScript выключен в конфиге
- **WHEN** в `.c4builder` `executeScript: false`, а плагин `openapi` подключён
- **THEN** сайт собирается с выполнением скриптов, о чём сообщается в логе

### Requirement: Источник — локальная папка или архив без авторизации по умолчанию

Плагин SHALL получать спеки через резолвер источников ядра. Для публичного или
внутренне-видимого репозитория `archive` MUST работать без заголовков авторизации; `headers` — опция.
При `dir` папка SHALL объявляться путём наблюдения для watch-режима; при `archive`
повторные сборки в одном процессе MUST переиспользовать скачанный архив.

#### Scenario: Архив без токена
- **WHEN** задан `archive` на архив репозитория с внутренней видимостью и `headers` не заданы
- **THEN** архив скачивается без заголовка авторизации, страницы строятся

#### Scenario: Локальная папка в watch-режиме
- **WHEN** источник — `dir` и в нём меняется спека при `-w`
- **THEN** сайт пересобирается с обновлённой спекой
