# regression-testing

## ADDED Requirements

### Requirement: Golden-тест покрывает D2-рендер
Golden-fixture SHALL включать `.d2`-диаграмму с импортом общего `.d2`-файла, а
golden-тест MUST сравнивать её SVG-выход с эталоном наравне с PlantUML-диаграммами.
Детерминизм D2-выхода обеспечивается вшитыми шрифтами и фиксированной версией пакета
движка; vendored-шрифт для D2 не требуется.

#### Scenario: D2-диаграмма в fixture совпадает с эталоном
- **WHEN** golden-тест собирает fixture, содержащий `.d2`-диаграмму с импортом
- **THEN** её SVG (после нормализации) совпадает с закоммиченным эталоном, а
  импортированные стили присутствуют в выходе

#### Scenario: Повторный прогон D2 идентичен
- **WHEN** сборка fixture с `.d2` выполняется дважды
- **THEN** SVG-выход D2-диаграммы байт-в-байт совпадает между прогонами
